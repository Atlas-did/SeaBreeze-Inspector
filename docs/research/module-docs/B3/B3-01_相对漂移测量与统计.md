# B3-01 悬停相对漂移测量与统计报告

> 本模块第一篇。把"0.531 m → 0.062 m"正确表述为"受控扰动下相对平面漂移的抑制"，并给出完整统计口径。
> 前置：B1-01 试验与测量链路。证据层 L2。

## 〇、前置判断

0.531→0.062 m 是两个**相对**数字（相对参考帧的平面位移）。它支持"相对漂移抑制约 88%"，**不支持**"±5 cm 绝对定位"。缺 RTK/动捕/激光真值时，任何"绝对定位误差"表述都越界（见 B3-02）。

## 一、问题严格定义

- 相对漂移：$$r(t)=(x_t,y_t)-(x_0,y_0)$$ 的统计量。
- 绝对定位：全局坐标误差，需外部真值系统。
- 本方案只做前者。

## 二、该做什么

1. 固定参考帧（起飞目标点=原点），固定俯视相机 + 标定输出每帧平面坐标。
2. 每 run：RMSE、95 分位、漂移轨迹。
3. 统计：按独立 run 求均值、SD、95% CI。
4. 改善率同时给绝对数与比例。
5. 统计协议：对比组合事前冻结、剔除按预声明规则、跨天复测一组验证可重复性。

## 三、技术方案

$$RMSE=\sqrt{\frac{1}{N}\sum_t(x_t^2+y_t^2)}, \qquad p95=\text{Quantile}_{0.95}\big(\|r(t)\|\big)$$

- 像素→米由标定棋盘格推导，记录换算系数与残差；试验固定高度。
- 分析脚本 `scripts/analyze_hover.py` 输出汇总表 + 差值 CI。

## 四、数据层

- telemetry + 标定文件 + 每帧平面坐标；参考帧定义写入 run_metadata.yaml。
- 汇总表字段：config, wind, N, rmse_mean/sd/p95, ci95_low/high, improvement_abs/pct。

## 五、可能踩的坑

1. 把相对当绝对。
2. 参考帧自己漂移（相机被吹动/震动）→ 相机牢固固定并校验。
3. 高度波动放大像素误差 → 固定高度。
4. 只报最好的一次 → 报均值与 CI。
5. 帧当样本 → 以 run 为单位。
6. 事后挖洞（p-hacking）→ 对比组合事前冻结。
7. 探索性写成结论 → N<10 或 CI 重叠时措辞降级。

## 六、评估指标与消融设计

- 主表：配置 × {RMSE, p95, 均值轨迹, N, CI}；改善率含差值 CI。
- 跨天复测可重复性表。

## 七、论文写法

可写：`在受控风扇扰动与固定参考帧下，前馈+EKF 使相对平面漂移 RMSE 由 0.531 m 降至 0.062 m（抑制约 88%，N=…，95% CI）。`

禁写：`±5 cm 绝对定位`、`厘米级定位精度`、`显著提升`（无 CI）。

## 八、诚实自评锚点

- **可交付**：参考帧定义 + 标定 + 统计 + CI。
- **部分完成**：仅单次演示 → 不写抑制比例。
- **不可声称**：绝对精度、厘米级定位、工业平台定位能力。
- **停止线**：参考帧无法固定或标定残差过大时停止统计。
