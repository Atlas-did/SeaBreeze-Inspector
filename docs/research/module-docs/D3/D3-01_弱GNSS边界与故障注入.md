# D3-01 弱 GNSS / 定位退化边界：故障注入与降级导航

> 本模块第一篇。**海上与盐雾环境下 GNSS 信号弱、多径、跳变是常态。本文量化"定位退化到什么程度系统还可用"，用故障注入（丢星、PDOP 恶化、位置跳变、漂移）测定位模块与下游（导航/控制）的边界。**
> 证据层 L2（注入台架）+ L4（推演）。

## 〇、前置判断

"GPS 弱"是一个连续谱：卫星数下降 → PDOP 恶化 → 位置误差增大 → 跳变/漂移。不能只测"有/无 GPS"。且定位误差要区分**精度退化**（缓慢变大）与**完整性退化**（跳变/漂移，可能静默）。本文两者都测，并明确：**演示平台（Tello）的视觉/惯性定位与工业 RTK 是不同的层级（见 B3-02），本方案的弱 GNSS 结论只覆盖所测层级的退化**。

## 一、问题严格定义

- GNSS 质量指标：卫星数 $$N_{sv}$$、PDOP、位置标准差 $$\sigma_{pos}$$、固定/浮点解。
- 退化注入：
  1. **精度退化**：$$\sigma_{pos}$$ 从 0.1m 递增到 10m+（模拟多径/遮蔽）；
  2. **完整性退化**：周期性跳变（位置突变 $$\Delta$$ 米）、慢漂移（叠加速度偏差）；
  3. **丢星/退化级**：N 级档位（健康→弱→极弱→无）。
- 下游边界：定位误差大到什么程度，感知（检测框地理投影）、控制（抗风悬停）、导航（到点）开始不可用。
- 输出：`定位退化 × 下游任务` 的可用性矩阵。

## 二、该做什么

1. 选定位接口：真实 GNSS 模块可注入（改 NMEA/UBX 流），或仿真替换（记录注入）。Tello 无 GNSS 时用其视觉/光流定位做"定位退化注入"的代理（明确代理声明）。
2. 实现注入器：在定位数据源层修改（不是改应用逻辑），支持档位/事件触发。
3. 测量每档下的定位误差（对基准）与下游任务指标。
4. 定义可用性阈值：如"检测框地理投影误差 <X m"、"悬停圆半径 <Y m"。
5. 输出边界表：退化档位 × 任务是否可用 + 转折点分析。

## 三、技术方案（要点）

- 注入实现（NMEA 层）：修改 `$GPGGA` 的纬度/经度字段加噪声/跳变；或 UBX 层加 bias。日志记录注入前后真实值，保证可核对。
- 代理说明：若用视觉定位代理 GNSS，必须写"代理不等价于 GNSS 多径效应"——视觉跳变与 GNSS 跳变机理不同。
- 边界判定：对每档做 N≥30 次重复，统计"任务成功"比例，用成功率 80%/90% 划可用线。

## 四、数据层

- 数据来源：本项目实机/台架注入数据 `d3_gnss_inject.csv`（档位、注入参数、定位误差、下游指标）。
- 参考：GNSS 性能指标（如 RTK 固定/浮点、PDOP 定义）来自标准文献——检索并记录来源 URL；不引用为"我们的测量"。

## 五、可能踩的坑

1. **只测"有/无 GPS"**：GPS 弱是连续谱，二分法测不出边界。至少 4–5 档。
2. **注入不可核对**：没记录真实注入强度，跳变被网络延迟掩盖，结论失真。
3. **把精度退化当完整性退化**：两者对策不同（前者滤波平滑，后者需完整性监测/拒跳）。分开测。
4. **代理定位冒充 GNSS**：Tello 视觉定位测不出"GNSS 多径"，论文里写明代理与差距。
5. **下游指标没定义**：不定义"可用"阈值，"边界"就没有落点。
6. **忽略跳变后的静默错误**：跳变若被滤波平滑成缓慢漂移，系统不报错继续错下去——完整性监测必须测"跳变是否被识别"。
7. **外推到工业 RTK**：演示平台的退化结论不直接适用 RTK 级（B3-02 已有边界说明），需在论文局限中明确。

## 六、评估指标与消融设计

- 主表：退化档位 × {定位误差, 检测投影误差, 悬停半径, 任务成功率}。
- 消融：有/无完整性监测（跳变识别）、滤波（KF 平滑 vs 无滤波）、注入类型（噪声/跳变/漂移）。
- 结论：`当 σ_pos 超过 …m 或跳变幅度超过 …m，检测地理投影误差超阈值，任务不可用`。

## 七、论文写法

可写：

> 通过定位注入（σ 0.1→10m、周期跳变 1–5m），量化定位退化边界：σ≤…m 时任务成功率 ≥90%，跳变幅度 ≤…m 时完整性监测可识别；超出后任务不可用。

禁写：`弱 GPS 下系统仍可用`（无条件范围）、`GNSS 可靠性验证`（无真实多径场景）、把视觉代理当 GNSS 结论。

## 八、诚实自评锚点

- **可交付**：注入器 + 档位矩阵 + 边界表 + 完整性监测消融。
- **部分完成**：只测了精度退化 → 完整性/跳变单列，论文标注。
- **不可声称**：RTK 级边界（未测）、真实海上多径、跨接收机一致性。
- **停止线**：注入不可核对、或"可用"阈值未定义时，停止边界结论。
