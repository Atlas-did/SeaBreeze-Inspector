## 每份文档的固定八节

〇 前置判断（能否做、边界在哪）／一 问题严格定义（符号、单位、任务区分）／二 该做什么（可执行步骤）／三 技术方案（公式、脚本、目录）／四 数据层（数据源与检索纪律）／五 可能踩的坑（预测并给出补救）／六 评估指标与消融设计／七 论文写法（可用与禁用措辞）／八 诚实自评锚点（可交付/部分/不可声称/停止线）。

## 证据层约定

- L1 软件/仿真；L2 Tello/SG90 台架；L3 锁定测试集+合成扰动；L4 参数化推演。
- 合成雾/模糊只支撑"合成扰动鲁棒性"；Tello 只支撑"小型平台/受控风场趋势"；力平衡只支撑"给定假设下的预测"；盐雾/防水/IP 未试验即列入局限性。

## 数据检索纪律

- 公开入口：[Kaggle Datasets](https://www.kaggle.com/datasets)、[Roboflow Universe](https://universe.roboflow.com/)、[Papers with Code Datasets](https://paperswithcode.com/datasets)、[OpenML](https://www.openml.org/)、[VisDrone](https://github.com/VisDrone/VisDrone-Dataset)、[SeaDronesSee](https://github.com/Ben93kie/SeaDronesSee)。
- 下载后必须核验许可证、来源、版本、标注格式、来源组、下载 SHA-256，写入 `data_sources.csv`；许可证不清的数据只作探索，不进主 test。
- 每个训练/试验数字必须回指 manifest、实验登记、原始日志、命令与模型 SHA-256；无 test lock 或原始记录时停止扩展结论。
