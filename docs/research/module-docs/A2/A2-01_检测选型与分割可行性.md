# A2-01 检测模型选型与分割可行性：v8n/s/m、分辨率与成本对照

> 本模块第一篇。回答"用哪个模型、什么输入尺寸"；同时判断 YOLOv8-Seg 在当前数据（只有 bbox 标签）下是否可行。
> 证据层 L3。

## 〇、前置判断

- 当前仓库标签是**框**（labelme→YOLO 检测格式），没有 polygon。没有 polygon，Seg 训练要么退化为"框内 mask"，要么需要新一轮标注战役。检测验收不依赖 mask。
- "把输入从 640 提到 1280"不是待做改进——**v3 已用 1280 训练**。正确对照是"1280 相对 640 的代价是否值得"。
- `backend/vision/train.py` 固定加载 `yolov8n.pt`，**必须先扩展 CLI** 才能比较规格。

## 一、问题严格定义

- 检测：1280×n → 框+置信；指标 mAP@0.5、mAP@0.5:0.95、P/R/F1。
- Seg（若立项）：输出实例 mask；指标 mask AP，与 box AP 不同，不能混报。
- 固定：锁定 split、seed=0、batch=8、epoch 上限、增强、early stop 全一致；只差模型规格/尺寸。

## 二、该做什么

1. 扩展 `train.py`：`--model yolov8n/s/m.pt`、`--project runs/binary`、`--name {model}-{imgsz}`、`--seed 0`、`--cls_pw`。
2. 跑 {n,s,m}×{640,1280}（+960 探索档）；显存超限**显式记录**并减 batch，或降 imgsz 全档重跑，不能悄悄改配置。
3. 每档记：epoch 数、训练墙钟、峰值显存、推理 P50/P95/P99（预热 50 帧 + ≥500 帧）、导出体积。
4. val 选一次主候选，test 只评一次。
5. Seg 可行性：统计有无 polygon；无 → 输出 polygon 标注成本估算（工具、双人复核、人天），请用户决定是否立项。

## 三、技术方案

```bash
python backend/vision/train.py --model yolov8n.pt --data data/processed/wind_turbine_defect_binary.yaml \
    --imgsz 1280 --batch 8 --epochs 200 --seed 0 --project runs/binary --name v8n-1280
```

- 显存参考（batch=8@1280，AMP）：n 约 6–8 GB，s 约 10–14 GB，m 可能超单卡 12 GB。
- 导出：`best.pt`→ONNX+TorchScript，记录导出命令、opset、输入尺寸、模型 SHA-256；导出后**在同一 test 重评**，报告导出前后 mAP 差值。
- 决策规则：`mAP@0.5 提升 ≥0.02 且推理 P95 不超目标时延`才升级一档。

## 四、数据层

- 训练 = A1-01 锁定 split，不新增。
- Seg 若立项：需 polygon 标签源。检索 `wind turbine blade polygon segmentation dataset`；SAM 辅助标注必须人工确认并保留原图 ID。
- 不要用检测框"假转"mask 训练 Seg——mask AP 虚高，实际边界能力为零。

## 五、可能踩的坑

1. n/s/m 同样 200 epoch 不算公平 → 用"固定早停 + 固定预算"两口径各出表。
2. batch 悄悄变小 → 增强统计/BN/mAP 全变，对照失效。
3. Seg 用框标签 → mask 是矩形填充，答辩穿帮。
4. 权重加载失败自动 mock → 选型表可能混入随机框数字。
5. 训练变慢与推理变慢混淆 → 分开报告。
6. 分辨率与模型同时改 → 无法归因；单一变量。
7. 用训练机测推理速度 → 与演示笔记本差数量级；指定设备。

## 六、评估指标与消融设计

- 主表：组合 × {mAP@0.5, mAP@0.5:0.95, AP_S/M/L, R, 训练h, 推理P95, VRAM, 体积}。
- 结论必须同时写"提升多少"与"贵多少"。

## 七、论文写法

可写：`在目标设备上，YOLOv8s@1280 相对 v8n@640 的 mAP@0.5 提升 Δ，但端到端推理 P95 由 X 增至 Y ms。`

禁写：`Seg 优于检测`（任务不同）、`更高分辨率必然更好`、跨设备 FPS 外推、`推理速度提升`（未测）。

## 八、诚实自评锚点

- **可交付**：组合表 + 成本表 + 导出重评 + 一句话决策建议。
- **部分完成**：只跑 n/s → 只报 n/s。
- **不可声称**：Seg 能力（无 polygon）、跨设备时延。
- **停止线**：显存不足未记录、或无法保证同配置时停止。
