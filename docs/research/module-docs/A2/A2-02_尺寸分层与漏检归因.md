# A2-02 尺寸分层评测与漏检归因：AP_S/M/L 的正确切法 + FN 根因

> 本模块第二篇。当整体指标提升有限时，用冻结的尺寸分档与 FN 根因把"差在哪里"讲清楚——这本身是论文最有价值的诚实内容。
> 证据层 L3。

## 〇、前置判断

COCO 的绝对像素分档不适用 1280 输入。正确做法：在锁定 test 上按 bbox 面积分位（或预设像素阈值）切档写入 `size_bins.json` 并冻结。某档样本数 <30 只作探索性结果。

## 一、问题严格定义

- 输入：锁定 test 的图 + 真值框 + 模型预测框。
- 输出：按尺寸档的 AP@0.5、Recall、FN 数与根因分布。
- 分档：按原图 bbox 面积 $$a=w_{px}h_{px}$$ 的分位或像素阈值（与训练 imgsz=1280 一致）。

## 二、该做什么

1. 冻结 `size_bins.json`（名称、面积区间、n 目标、n 图像）。
2. 每档：AP@0.5、Recall、FN 列表、平均预测框面积 vs 平均真值框面积。
3. 全部 FN 逐框打根因标签（双人独立 + 一致率）。
4. 两张图：每档 Recall 柱状图；FN 根因堆叠图。
5. 若小目标档 Recall 显著低 → 把结论指向 A4（SAHI/copy-paste/超分），明确"这是归因，不是解决"。

## 三、技术方案

```python
SIZE_BINS = {'S': {'max_area_px': 0.10*(1280*720)},
             'M': {'max_area_px': 0.30*(1280*720)},
             'L': {'max_area_px': float('inf')}}
```

- 统计按**真值框面积**归档；预测框面积只作辅助。
- FN 根因（至少）：极小目标、低对比度、模糊、遮挡、标注问题、背景相似、NMS 合并、置信度过低。
- 输出 `fn_taxonomy.csv`：`image_id, gt_box, pred_box, iou, reason, reviewer`。

## 四、数据层

- 完全使用锁定 test；每档 n 与图像数必须记录。
- 若做 SAHI/copy-paste 消融（A4），基于本表报各档变化；本表先出归因。

## 五、可能踩的坑

1. 分档在 test 上事后调整 → 变相过拟合；先在 val 定档。
2. 直接抄 COCO 绝对像素 → 1280 输入下绝大多数框挤进 S 档。
3. FN 根因凭印象打 → 必须双人独立 + 一致率。
4. NMS 吞框误记成漏检 → 用去 NMS 的调试输出区分。
5. 样本不足仍写强结论 → 表头写 n=15 而不是藏着。
6. 小目标提升被归因错 → 若来自分辨率而非 SAHI，须区分。

## 六、评估指标与消融设计

- 主表：档位 × {n, AP@0.5, Recall, FN}。
- 辅助：FN 根因堆叠图、每档平均置信度分布（低置信漏检 vs 高置信漏检是不同问题）。
- 若做 SAHI/copy-paste 消融（A4），基于本表报各档变化；本表先出归因，消融另出。

## 七、论文写法

可写：`漏检集中在面积 <X px 的档位（n=…，Recall=…），主要根因为低对比度（…%）与极小尺寸（…%）。`

禁写：`小目标检测已解决`、`AP_S 显著提升`（无归因与样本量）、根因"自动标注"未复核。

## 八、诚实自评锚点

- **可交付**：冻结分档 + 每档 n/AP/Recall + 双人复核根因。
- **部分完成**：只有自动分档无人工根因 → 只报数字不报根因。
- **不可声称**：小目标已解决、样本不足档的强结论。
- **停止线**：bbox 面积不可复现或 test 未锁定时停止。
