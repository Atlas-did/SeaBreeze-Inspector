# D1-02 六自由度晃动轨迹到成像模糊核：仿真耦合与不确定性

> 本模块第二篇。**把"真实晃动"接进模糊模型：用无人机 6-DoF 轨迹仿真，推出快门时间内的相机轨迹，再推出成像 PSF。比 D1-01 的参数化核更接近物理，但代价是引入新的假设（惯性、控制、相机模型）。本文明确写清每一步的假设与不确定性，避免"仿真=真实现实"。**
> 证据层 L1（仿真）+ L4（推演）。

## 〇、前置判断

参数化核（D1-01）能评估"鲁棒性"但回答不了"真实晃动下模糊长什么样"。真实模糊由相机在曝光窗口内的 6-DoF 轨迹决定：姿态角速度 → 像平面位移；平动（平移）→ 视差位移（与深度相关）。完整建模需要姿态轨迹 + 相机内参 + 场景深度，三层都带不确定性。本文目标是**可控的耦合仿真**：轨迹模型可调、参数可审计、输出"成像核族"，而非"唯一真实核"。

## 一、问题严格定义

- 输入：晃动轨迹（角度/角速度时程，来自 B1 风场/悬停实测或参数化模型）、曝光时间 $$\Delta t$$、相机内参（f 像素焦距）。
- 姿态转动 → 像面位移：$$\Delta x \approx f\,\Delta\theta_x$$（小角度近似，$$\Delta\theta_x$$ 为俯仰角变化）。
- 平动 → 像面位移：深度相关，$$\Delta x \propto f\, v_x \Delta t / Z$$。
- 成像核：把曝光窗内的位移轨迹离散化为 PSF（同 D1-01 的核，但从轨迹导出而非参数化生成）。
- 输出：给定轨迹段 → 成像核 + 每核的"来源分解"（转动占比 vs 平动占比）。

## 二、该做什么

1. 选轨迹源：优先 B1 悬停实测的姿态角时程（最真实）；无则参数化（白噪声 + 1/f 谱）并写明。
2. 配相机模型：内参（焦距、像素尺寸）、曝光时间（如 1/60s / 1/120s）。
3. 实现轨迹→PSF：对每个 (t, pose) 采样，投影到像平面，累积位移直方图 → 核。
4. 生成核族：多段轨迹（轻晃/中晃/大晃）、多曝光 → 每段一个核。
5. 用核族评估检测模型（同 D1-01 协议），并对比"参数化核 vs 轨迹导出核"的差异。
6. 灵敏度：角速度、曝光、深度这三类参数 ± 扫，看核形状与 mAP 变化。

## 三、技术方案（要点）

```python
import numpy as np

def trajectory_to_psf(pitch, yaw, dt_expose, f, W, H, depth=None, k=33):
    # pitch/yaw: 曝光窗内角时程(rad); 小角度近似
    dx = f * np.diff(yaw) * dt_expose          # 横向像面位移
    dy = f * np.diff(pitch) * dt_expose
    if depth is not None:                       # 平动耦合(速度xdt/Z)
        dx += f * vx * dt_expose / depth
    hist, _, _ = np.histogram2d(dy, dx, bins=k, range=[[-k//2,k//2]]*2)
    return hist / (hist.sum() + 1e-9)
```

- 曝光窗内轨迹采样率要 ≥ 2× 晃动频率，否则轨迹欠采样、核失真。
- 深度项：若场景深度未知，给出"深度范围假设"并注明由此带来的核不确定性。
- 对比项：相同 mAP 口径下，参数化核（D1-01）与轨迹核的评估差异 → 回答"参数化是否足够"。

## 四、数据层

## 五、可能踩的坑

1. **小角度近似失效**：大晃（>10°）下线性近似偏差大，核形状失真。超范围时用完整旋转矩阵投影。
2. **平动深度没交代**：忽略平动项而场景有深度 → 核被低估。要么给深度假设，要么写明"仅姿态转动建模"。
3. **欠采样轨迹**：轨迹采样率低于晃动频率，核丢失高频摆动细节。
4. **把仿真核当唯一真值**：轨迹模型、相机模型、深度假设都带不确定性，输出是"核族"不是"真核"。论文写范围。
5. **轨迹源与风场不匹配**：B1 风场强度 ↔ 晃动幅度要有对应标定，否则"大晃"核无依据。
6. **评估协议漂移**：mAP 口径与 D1-01/A2 保持一致，否则两张曲线不可比。
7. **"仿真=实测"表述**：仿真核只能支撑"模型一致"，不能支撑"真实飞行模糊验证"。

## 六、评估指标与消融设计

- 输出：每轨迹段的核可视化（heatmap）+ mAP 曲线。
- 消融：轨迹源（实测 vs 参数化）、曝光时间（1/60 vs 1/120）、深度假设（有/无）、转动 vs 平动贡献。
- 对比：轨迹核 vs D1-01 参数化核的 mAP 差异表 → 回答"参数化是否足够"（若差异 < 阈值，说明线性核够用，是值得写的负结果）。

## 七、论文写法

可写：

> 将悬停姿态轨迹投影为成像核（转动主导，深度项在 Z∈[2,10]m 下贡献 <x%），所得核族下的 mAP 衰减与参数化核差异 ≤Δ，表明线性近似在该工况足够。

禁写：`真实晃动模糊验证`（仿真）、`核精确复现真实退化`（模型+假设）、无灵敏度分析的核结论。

## 八、诚实自评锚点

- **可交付**：轨迹→PSF 脚本 + 核族 + 灵敏度表 + 与参数化核对比。
- **部分完成**：只有参数化轨迹 → 明确标注"参数化轨迹，待 B1 实测接入"。
- **不可声称**：真实飞行模糊、深度无关性（未测）、跨平台轨迹外推。
- **停止线**：轨迹采样率未校验、或深度/曝光假设未声明时，停止核结论。
