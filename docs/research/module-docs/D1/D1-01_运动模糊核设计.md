# D1-01 运动模糊核设计：参数化退化与鲁棒性量化

> 本模块第一篇。**无人机在风/晃动下拍摄的图带有运动模糊。本文定义可控的参数化模糊核（方向、长度、抖动），并把它做成可复现的退化协议，用于评估检测/特征一致性模型的模糊鲁棒性——与 A3 的雾扰动协议并列。**
> 证据层 L3（合成扰动）。

## 〇、前置判断

运动模糊不是"一种模糊"，它是**点扩散函数（PSF）**：快门时间内场景在像面上的积分轨迹。真实模糊与相机姿态轨迹、曝光时间、焦距、场景深度都耦合。本文只做参数化核（线性 + 轻微曲线抖动），可控可复现；真实 6-DoF 耦合留给 D1-02。先给一个干净的合成扰动协议，再谈仿真耦合。

## 一、问题严格定义

- 连续域：$$I_b(x) = \int_{\tau=0}^{\Delta t} I_{\text{clean}}\big(x - v(\tau)\Delta\tau\big)\,d\tau$$（短曝光内的匀速近似）。
- 离散参数化：线性运动核 $$K(\theta, L)$$：长度为 $$L$$（像素）、方向 $$\theta$$ 的直线卷积核，可叠轻微随机抖动（高斯噪声系数 $$\sigma_j$$）。
- 对每张 clean 图：以概率 $$p$$ 施加核（方向按平台晃动分布采样，长度按风速/姿态速率分布采样）。
- 输出：`fuzzy_pairs.csv`（clean, blurred, theta, L, seed）+ 评估协议。
- 边界：合成线性模糊 ≠ 真实 6-DoF 模糊（D1-02 处理）；模糊与雾/盐雾可叠加（A3 中已有说明）但要分开评估。

## 二、该做什么

1. 写核生成器：`motion_kernel(theta, L, sigma_j, k)`，k 为核尺寸。
2. 参数分布：$$\theta\sim U(0,360°)$$（或按平台姿态谱），$$L\sim$$ 按实测晃动幅度标定（可先取 `{4, 8, 12, 16, 24}` 像素档）。
3. 生成模糊图并落盘 pairs.csv + 每档抽样人工看。
4. 评估：对候选检测模型，逐档 $$L$$ 报告 mAP@0.5 衰减曲线（与雾曲线并列）。
5. 若做特征一致性训练（A3-02），把模糊扰动并入配对协议，比较"仅雾" vs "雾+模糊" 的鲁棒性。

## 三、技术方案（要点）

```python
import numpy as np
import cv2

def motion_kernel(L, theta, sigma_j=0.0, k=None):
    L = max(int(L), 2)
    k = k or int(L) + 2
    # 单位方向
    a, b = np.cos(np.deg2rad(theta)), np.sin(np.deg2rad(theta))
    xs, ys = np.linspace(-L/2, L/2, L), np.linspace(-L/2, L/2, L)
    pts = np.vstack([xs*a - ys*b, xs*a + ys*b]).T + (k//2)
    img = np.zeros((k, k))
    for x, y in pts:
        img[int(round(y)), int(round(x))] = 1
    if sigma_j > 0:
        img += np.random.normal(0, sigma_j, img.shape)
    return img / (img.sum() + 1e-9)

def apply_blur(img, L, theta):
    ker = motion_kernel(L, theta)
    return cv2.filter2D(img, -1, ker)
```

- 抖动项 $$\sigma_j$$ 模拟手持/晃动的不规则轨迹；论文里写明它是"轨迹抖动"，不是噪声。
- 核旋转应避免整数网格化失真：先做线性核再旋转，或用 subpixel 采样。核尺寸 $$k\ge L+2$$ 防止截断。

## 四、数据层

- 每档 $$L$$ 至少保留 20 张人工看图样本。

## 五、可能踩的坑

1. **核生成退化**：整数网格化让短核（L=4）变成奇怪的"阶梯"形状，模糊强度失真。用浮点采样 + 旋转后重建。
2. **边界伪影**：`filter2D` 默认边界填充在角落引入暗边，检测器可能学到"边缘黑框"。用 BORDER_REFLECT。
3. **参数分布与实测脱节**：$$L$$ 的上限不来自任何晃动实测，曲线右端的"浓模糊"就是虚构。若 B1 有姿态速率实测，用它标定。
4. **模糊与雾叠加无法归因**：雾+模糊一起加，掉点说不清。分开评估，需要时再叠加并写明"联合扰动"。
5. **把合成模糊当真实模糊**：线性核≠6-DoF；论文写"参数化运动模糊扰动"，域外真实模糊失败要如实写。
6. **只测一种核**：方向、长度都扫，画 2D 热图（mAP 随 θ×L），比单条曲线信息量大。
7. **评估协议不一致**：测试集、置信阈值、NMS 参数必须与 A2/A3 保持一致。

## 六、评估指标与消融设计

- 主表：mAP@0.5 / P / R 随 $$L\in\{0,4,8,12,16,24\}$$ 的曲线；θ×L 热图。
- FN 归因：模糊导致的漏检率（与 A2-03 尺寸分层交叉：小目标在模糊下最先崩）。
- 消融：仅模糊 / 模糊+雾 / 模糊+雾+特征一致性（A3-02 模型）；每格 N 与 CI。
