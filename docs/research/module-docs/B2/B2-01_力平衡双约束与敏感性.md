# B2-01 力平衡抗风模型：双约束解析与区间敏感性（含蒙特卡洛）

> 本模块第一篇。用双推力约束把"最大可平衡风速"算成区间内的可行域，并做参数敏感性传递不确定性。
> 前置：目标平台参数表（必须用户提供）。证据层 L4。

## 〇、前置判断

单一稳态公式不足以证明"6 级风可作业"。垂直方向要维持高度（$$T\cos\theta \ge mg/\eta_v$$），水平方向要对抗阻力（$$T\sin\theta \ge D(v)/\eta_h$$），两条共同限定。且输入（质量、连续推力、$$C_DA_{eff}$$、最大倾角）都是区间，不是精确数。

## 一、问题严格定义

$$D(v)=\frac{1}{2}\rho\,C_D A_{\mathrm{eff}}\,v^2, \qquad T\cos\theta \ge \frac{mg}{\eta_v}, \qquad T\sin\theta \ge \frac{D(v)}{\eta_h}$$

- $$T$$：可用**连续**推力（非峰值）；$$\theta$$：最大允许倾角；$$\eta_v,\eta_h$$：电池衰减/姿态/控制裕度系数（<1）；$$C_DA_{eff}$$：区间输入。

## 二、该做什么

1. YAML 固化输入（质量、连续推力、迎风面积范围、最大倾角、密度、SOC、裕度），每项标来源或"用户提供/设计假设"。
2. 解析解双约束交集 → 可行域图。
3. 网格 + 蒙特卡洛（≥5000 样本）：对每采样点解双约束，得 $$v_{max}$$ 分布与"在 10/12/14 m/s 下满足比例"。
4. 敏感度排序（一次一个参数全区间 vs 其余固定）。
5. 阵风校核：简化阵风谱作为外扰，报告在控制带宽假设下的最大姿态、饱和率、恢复时间。
6. 结论模板见第七节，与"已验证可作业"明确区分。

## 三、技术方案

```yaml
platform: T1_x500
mass_kg: [3.2, 3.8]
T_continuous_N: [60, 80]
theta_max_deg: [20, 30]
C_D_Aeff_m2: [0.35, 0.55]
rho_kg_m3: [1.15, 1.225]
eta_v: 0.75
eta_h: 0.60
```

- 求解：$$v_{max} = \min(v^{(h)}, v^{(v)})$$，水平约束由 $$D(v)=\eta_h T\sin\theta$$ 解出，垂直约束限倾角。
- 模块化：`scripts/wind_resistance_model.py` + `tests/test_wind_resistance_model.py`（单位换算、极限条件）。
- 输出：$$v_{max}$$ 直方图、tornado 敏感性图、可行比例表、阵风校核表。
- MC 收敛检验：结果随样本数变化 <阈值才算收敛。

## 四、数据层

- 目标平台参数**必须来自真实设计表或用户提供**；没有就输出"待补参数清单"。
- Tello 实测（B1-01）只能作模型结构/量级的合理性检验，不能当 3.5 kg 平台输入。

## 五、可能踩的坑

1. 用瞬时峰值推力 → 悬停抗风需要连续推力。
2. $$C_DA_{eff}$$ 当精确常数 → 必须区间 + 敏感性。
3. 只算水平约束 → 倾角受限会先失效。
4. 跳过阵风 → 稳态可平衡 ≠ 阵风下姿态不饱和。
5. 相关参数当独立采样（质量与推力常同源）→ 联合分布或注明。
6. 密度随温度/高度变化 → 给区间。
7. 把"可行比例 80%"写成"80% 时间可作业" → 那是参数空间比例。
8. 结论给单一精确数字 → 给区间与假设清单。

## 六、评估指标与消融设计

- 输出：可行域图、$$v_{max}$$ 区间、敏感度排序、MC 收敛检验、可行比例表、阵风校核表。
- 结论稳健性：不同采样策略（均匀 vs 三角）下可行比例变化 <10 个百分点。

## 七、论文写法

可写：`在所列质量、连续推力、最大倾角、空气密度及气动阻力区间假设下，参数化力平衡模型给出目标平台在 12 m/s 来流下具有正水平推力裕度的预测。该结果不替代工业平台阵风环境实飞验证。`

禁写：`工业平台已验证可稳定作业`、`6 级风实飞通过`、`抗风能力为 X m/s`（单值）。

## 八、诚实自评锚点

- **可交付**：参数表 + 双约束求解 + MC + 敏感度 + 假设清单。
- **部分完成**：缺平台参数 → 只给符号模型与需求范围。
- **不可声称**：实飞验证、阵风通过、平台稳定性（未测闭环）。
- **停止线**：参数无来源或区间未定义时停止数值结论。
