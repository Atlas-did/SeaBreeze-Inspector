# B2-02 Tello 实测到工业六旋翼外推：禁用边界与量级讨论

> 本模块第二篇。明确"什么能从 Tello 学到、什么不能"，守住"小型机趋势 ≠ 工业机能力"的红线。
> 前置：B1 台架数据 + B2-01 模型。证据层 L4（仅量级/趋势）。

## 〇、前置判断

Tello 与工业六旋翼在桨盘载荷、雷诺数、推力曲线、气动外形、控制带宽上都不是同一量级。从 Tello 拟合的任何风阻/控制参数**都不能直接迁移**。能迁移的是：控制算法结构、扰动响应趋势、观测器机制、试验方法论。

## 一、问题严格定义

- 能学的：控制器相对表现趋势、扰动观测器能否跟踪风速、试验协议可行性。
- 不能学的：$$C_DA_{eff}$$ 数值、可平衡风速数值、桨盘载荷相关效率、绝对稳定性。
- 若硬要拟合 Tello 风阻参数：只能得到"小型机在实验风场下的风阻参数"，报告 CI 与风速范围，不换算到大机。

## 二、该做什么

1. 把 Tello 数据用途限定为：模型结构验证 + 参数合理性检验 + 趋势展示。
2. 若拟合 $$C_DA_{eff}$$：多风速点回归 + CI，明确"仅对 Tello 构型有效"。
3. Froude 相似律只放附录作量级讨论，写明：无人机气动更关键的是雷诺数、桨盘载荷、推力曲线、姿态限幅与控制饱和。
4. 输出外推矩阵。

## 三、技术方案（外推矩阵）

| 结论类型 | Tello 台架 | 工业六旋翼 | 可否迁移 |
|---|---|---|---|
| 控制算法结构（前馈+观测器） | ✓ 验证 | 设计移植 | 可（需重标定） |
| 扰动响应趋势 | ✓ | 参考 | 可（仅趋势） |
| $$C_DA_{eff}$$ 数值 | ✓ 拟合 | ✗ | **禁止** |
| 可平衡风速 | ✓ 推算 | ✗ | **禁止** |
| 桨盘载荷/效率 | ✗ | ✗ | 禁止（需新数据） |

## 四、数据层

- Tello 数据只进入"小型机构型"统计表。
- 工业平台任何数值需独立参数表（B2-01）或实机数据；不存在的写"待提供"。

## 五、可能踩的坑

1. 量纲换算的诱惑：按面积等比放大 $$C_DA$$ = 伪科学（雷诺数差两个量级，系数不守恒）。
2. Froude 相似律误用：它是自由面/波相似，不是气动-控制相似。
3. 把"趋势"说成"能力"。
4. 拟合外推超风速范围。
5. 忽略控制带宽差异。

## 六、评估指标与消融设计

- 输出：外推矩阵、Tello 拟合参数（含 CI 与风速范围）、附录量级讨论（含禁用声明）。

## 七、论文写法

可写：`小型平台试验用于验证控制结构、扰动响应趋势与试验方法；工业平台的气动参数与抗风能力需在对应构型上独立标定与验证。`

禁写：`Tello 实测验证了工业平台抗风能力`、`按比例放大后适用于工业机`。

## 八、诚实自评锚点

- **可交付**：外推矩阵 + 禁用项 + 量级讨论。
- **部分完成**：只有 Tello 数据 → 结论止于小型机趋势。
- **不可声称**：工业平台任何能力、气动相似、参数迁移。
- **停止线**：任何"从 Tello 直接推出工业机"的表述出现时先删。
