# C2-02 从演示机构到工业关节配置：外推需求清单与逐项证据边界

> 本模块第二篇。**"本演示的舵机方案可以迁移到工业无人机"是一句需要拆成具体条款的话。本文把迁移拆成一张需求清单：每一项给"当前演示的证据""工业需要的证据""还没有的证据"。只允许在证据齐的条款上写外推结论。**
> 证据层 L4（参数化推演）+ L1/L2 已有证据。

## 〇、前置判断

工业迁移不是"换个贵舵机"那么简单。每个关节配置（云台电机、无刷直驱、伺服+减速箱、编码器闭环）对应不同的控制、标定、失效模式、成本/质量预算。本文的立场：**外推必须逐项声明证据等级**，演示平台上的 L2 证据能支撑"方案在低精度轻载场景可行"，不能直接支撑"已满足工业可靠性"。诚实清单比模糊的"可迁移"值钱得多。

## 一、问题严格定义

- 迁移对象：从 Tello/SG90 演示平台（B/C 模块实测对象）到工业海上无人机（云台、叶片偏转、稳定系统）。
- 需求维度（每项都给三级证据）：
  1. **精度/分辨率**：需要的末端定位精度 vs 演示的 ±1–2° 重复性；
  2. **负载/力矩**：真实叶片的空气动力负载 vs 演示的空载/轻载；
  3. **闭环能力**：是否需要编码器/IMU 反馈（抗风稳定，见 B1）；
  4. **环境**：盐雾/IP 等级、温度、湿度（见 D3-02）；
  5. **可靠性/寿命**：连续工作小时数、MTBF、失效模式；
  6. **时延**：关节指令周期 vs D2 的系统时延预算；
  7. **成本/质量**：单位成本、总质量对续航的影响。
- 输出：一张需求清单表，每项标注 `已证实 / 部分证实 / 未证实` 与证据来源。

## 二、该做什么

1. 把上表做成 `requirements_matrix.md`（或 CSV），逐项写证据与缺口。
2. 对"已证实"项：引用对应模块的实测数字（C1、B1、D2）。
3. 对"未证实"项：写明需要什么实验/数据才能证实（例如"风洞测叶片力矩"）。
4. 参数化推演：用演示数据反推"在工业参数下需要什么"（如力矩缩放、闭环需求），给出量级结论。
5. 论文局限性章节引用此表：外推结论只覆盖已证实项。

## 三、技术方案（要点）

- 推演公式示例（力矩需求）：叶片空气动力矩 $$M \approx \tfrac12 \rho C_m A r^2 \omega^2$$；对比 SG90 额定力矩，得到"演示舵机力矩余量/缺口"量级。
- 精度外推：工业云台若要求指向误差 <0.1°，开环舵机+无编码器直接出局 → 需求写"需编码器闭环"；这一步的结论是**需求层面的**，不是"我们做到了"。
- 每项给出证据链：`观测 → 模型 → 外推 → 边界条件`。

## 四、数据层

- 输入：C1-01/02（舵机重复性）、B1（风场/扰动力矩量级）、D2（时延预算）、B2（Tello→工业机外推边界）。
- 工业规格书：检索商用云台/舵机/伺服规格（力矩、分辨率、IP 等级、寿命），逐条记录 URL、型号、日期；用于"工业需要什么"而非"我们达到了什么"。
- 数据源检索：厂商手册（如 DJI 云台规格、工业舵机 datasheet）、论文中的执行器选型表格。写入 `data_sources.csv`。

## 五、可能踩的坑

1. **用玩具级数据推工业结论**：SG90 ±2° 重复性推"工业云台 ±0.1° 可行"是数量级错误。推演必须带量级核对。
2. **把"需求"写成"已达成"**：需求清单里的"需编码器闭环"是需求，不是我们实现了闭环。措辞必须区分。
3. **忽略负载**：空载演示 → 真实叶片的力矩/气动耦合完全不同。力矩项必须有量级推演。
4. **忽略环境**：盐雾、IP 防水对执行器是硬约束（D3-02），不能一句"可加防护"带过。
5. **忽略时延**：工业稳定控制对关节延迟极其敏感；D2 的时延预算要逐项对照。
6. **成本/寿命不写**：迁移决策绕不开的单位成本与 MTBF，缺了就是"纸面迁移"。
7. **论文里写"满足工业应用需求"**：只覆盖已证实项；未证实项必须列在局限性。

## 六、评估指标与消融设计

- 输出：需求矩阵（每项 `需求值 | 演示证据 | 缺口 | 需做什么`）。
- 推演灵敏度：力矩/精度/时延公式的参数 ±50% 扫一遍，看结论（可行/不可行）是否翻转——翻转点即"证据边界"。
- 结论模板：`在精度 ≤±2°、轻载、无盐雾工况下，演示方案可迁移；超出该工况，需以下未证实证据：……`。

## 七、论文写法

可写：

> 面向工业部署，本文给出关节配置需求清单（表 X）：演示证据覆盖轻载/低精度/无盐雾工况；力矩与闭环需求（…）尚需风洞与编码器闭环实验，属本工作边界。

禁写：`可直接迁移到工业平台`、`满足海上长时间作业需求`、用需求清单冒充实测结果。

## 八、诚实自评锚点

- **可交付**：需求矩阵 + 参数化推演 + 灵敏度分析 + 证据边界清单。
- **部分完成**：推演只有量级 → 标注"量级估计，待风洞/实测校准"。
- **不可声称**：任何未证实项的"已满足"、工业可靠性/寿命结论。
- **停止线**：推演公式参数无来源、或需求值无证据时，停止外推结论。
