# C2-01 运动学 FK/IK 数值自洽验证与奇异位形审计

> 本模块第一篇。**本演示用的是简单的单/双自由度云台与叶片机构，但"运动学正确"必须有硬证据：正解/逆解数值互验、雅可比奇异性、奇异附近数值爆炸。先把这一层钉死，再谈"向工业关节配置迁移"（C2-02）。**
> 证据层 L1（数值自洽）+ L2（台架对照）。

## 〇、前置判断

FK（关节角 → 末端位姿）与 IK（末端位姿 → 关节角）的"正确性"分两层：**数值自洽**（FK∘IK = 恒等，IK∘FK = 恒等，至少在你的工作空间内）和**物理正确**（算出的关节角真的把机构带到位姿——那要靠 C1 台架实测佐证）。本方案解决第一层；第二层是 C1/C2-02 的联合议题。很多"运动学方案"翻车在：IK 用解析解但没处理多解/无解，或数值 IK 在奇异点附近迭代爆炸，表面 mAP/成功率很高其实是伪自洽。

## 一、问题严格定义

- 机构：本演示平台 = 相机云台（1–2 轴）+ 叶片偏转（1 轴），真实自由度少；但为论文可写性，把它形式化为 $$n$$ 自由度链。
- FK：$$T(\mathbf{q}) = \prod \operatorname{Trans}_i \operatorname{Rot}_i(\theta_i)$$（齐次变换矩阵）。
- IK：给定末端目标位姿 $$T_d$$，求 $$\mathbf{q}$$ 使 $$T(\mathbf{q})\approx T_d$$。
- 验证指标：
  1. **FK∘IK 闭环误差**：对工作空间内采样 N 个目标位姿，解 IK 得 $$\mathbf{q}$$，再 FK 回代，比较位姿残差；
  2. **IK∘FK 闭环误差**：对关节空间采样 N 个 $$\mathbf{q}$$，FK 得位姿，再 IK 解回，比较关节残差；
  3. **奇异审计**：在奇异位形附近 $$\det(J) \to 0$$，IK 误差/迭代次数爆炸——量化奇异半径。
- 边界：数值自洽 ≠ 物理可达（要 C1 台架实测对照）；也不等于满足工业迁移要求（那是 C2-02）。

## 二、该做什么

1. 形式化机构：DH 参数表（或 SE(3) 基元），写 FK/IK（解析优先；数值用 Levenberg–Marquardt）。
2. 写验证脚本：工作空间与关节空间均匀采样（网格 + 随机，各 ≥10⁴ 点），跑闭环误差统计。
3. 奇异审计：扫描关节空间，画 $$|\det J|$$ 热图，标奇异位形；测奇异附近 IK 残差与迭代次数。
4. 台架对照（至少一个位形）：用 C1 台架把 IK 解出的角度送到 SG90，比较"预测末端"与"实测末端"。
5. 输出：自洽误差分布（P50/P95/P99）、奇异位形清单、台架对照表。

## 五、可能踩的坑

1. **在不可达区域采样**：IK 失败率被非工作空间样本撑高，数字没有意义。采样范围必须由机构可达性限定。
2. **闭环误差只报均值**：P99 才是该报的——奇异附近会有一批大残差，均值好看不代表可靠。
3. **IK 多解没处理**：IK∘FK 里如果多个解对应同一末端，回代"关节残差"会虚高或虚低。必须定义"最近解"选择策略。
4. **奇异检测只看 det**：det J 的量纲与尺度相关，用条件数 $$\kappa(J)$$ 更稳。
5. **把数值自洽当物理正确**：自洽误差 1e-12 不代表 SG90 真的到那个位姿（C1 的重复性是 1–2°）。物理对照必须有。
6. **雅可比奇点混入可逆**：奇异附近数值 IK 可能收敛到错误分支，输出看似成功实则错位姿。检查迭代轨迹与条件数。
7. **论文里吹"高精度运动学"**：演示平台是低自由度简单机构，自洽性好是应该的；重点写"验证协议"而非"精度数值"。

## 六、评估指标与消融设计

- 主表：FK∘IK 与 IK∘FK 的位姿/关节误差 P50/P95/P99 + 失败率。
- 奇异审计：$$\kappa(J)$$ 分布、奇异位形清单、奇异半径（误差 > 容差的邻域半径）。
- 消融：数值 IK 的初始化策略（零初值 vs 上次解）、容差设置；解析 vs 数值 IK 的失败率对比。
- 台架对照：至少 3 个位形的"预测 vs 实测"偏差表。

## 七、论文写法

可写：

> 在工作空间 2×10⁴ 采样点上，FK∘IK 位姿闭环误差 P95 为 …，奇异位形距工作空间边界 …；台架对照显示预测末端与实测偏差 …，与 C1 重复性一致。

禁写：`运动学精度 1e-6`（那是数值自洽，不是物理精度）、无奇异审计的 IK 结论、把数值自洽当物理可达。

## 八、诚实自评锚点

- **可交付**：自洽验证脚本 + 误差分布 + 奇异审计 + 台架对照。
- **部分完成**：只有数值自洽 → 论文写"数值自洽"，物理可达另需台架实测。
- **不可声称**：工业级运动学性能、大自由度机构的普适性（仅演示机构）。
- **停止线**：采样范围未限定工作空间、或台架对照缺失时，停止"运动学验证"结论。
