# A4-03 小目标增强·超分预处理：Real-ESRGAN 等方案的端到端取舍

> 本模块第三篇。**当切片/重训路线都受限时，评估"先超分再检测"的可行性；重点算清端到端延迟、显存与"超分伪造纹理"的风险。大多数情况下它不如切片或直接高分辨率重训。**
> 前置：A2 候选权重；A4-01 时延协议。证据层 L3。

## 〇、前置判断

超分预处理（推理时先把整图或目标区域 2×/4×，再送检测）看起来直接，但有三个系统性代价：(1) 端到端延迟至少翻倍以上；(2) 超分网络在真实图像上会**幻觉细节**，伪纹理可能被检测器当缺陷边缘，也可能把真实细纹抹平；(3) 超分不能创造真实信息——它只是基于先验补细节。因此它多数时候是**兜底方案**，排在"高分辨率重训"和"SAHI 切片"之后。

## 一、问题严格定义

- 输入：候选模型 + 超分网络（如 Real-ESRGAN 的 4× 模型，GitHub: xinntao/Real-ESRGAN）。
- 两种路径：
  1. **推理时超分**：`I → SR(I) → detect`，整图或仅目标区域；
  2. **训练时超分**：把低清目标 patch 超分后加入训练集（数据制造，需严格审计）。
- 输出：端到端时延、mAP/P/R、FN 变化、伪影统计。

## 二、该做什么

1. 先跑小实验：对锁定 test 的 S 档目标，用 2×/4× 超分前后各检测一次，看 AP_S 是否真的提升（很多情况是没提升甚至下降）。
2. 若有效，做整图推理的端到端时延测量（超分 + 检测，P50/P95/P99）。
3. 伪影审计：超分输出上"不存在于原图的边缘/纹理"人工抽检。
4. 与 A4-01（SAHI）和 A2-02（高分辨率重训）对比：谁在"单位时延下 AP_S 提升"更大。
5. 训练时超分：只在明确立项且样本可审计时做；写入 manifest 的 `aug_source`。

## 三、技术方案（要点）

- 推理链路：`openCV/PIL 读图 → SR 前向（GPU 或 CPU）→ 检测前向 → 后处理`。超分前向在 1280 图上做 4× 是 5120×n，显存与耗时都很可观——必须实测，别估。
- 目标区域超分：先粗检测定位候选框，再只对框内区域超分重检——省算力但引入两阶段延迟与"粗检漏了就没有重检"的问题。
- 与 SAHI 组合顺序：先切片再超分（每片小图超分）or 先超分再切片，结果不同且成本叠加，需单独比较。

## 四、数据层

- 评估：A1-01 锁定 test。
- 训练时超分若启用：只对锁定 train 中面积过小的目标 patch 做，输出 `sr_train_manifest.csv`（原图、patch 坐标、超分模型版本、seed）。
- 公开超分模型/数据检索：`Real-ESRGAN`（GitHub 官方仓库，含训练数据说明）、`BSRGAN`、低光/模糊修复模型；许可证与商用限制需核验后写入 `data_sources.csv`。

## 五、可能踩的坑

1. **伪纹理被当缺陷**：超分幻觉的边缘被检测器判为裂纹/腐蚀 → Precision 崩。必须做伪影审计。
2. **细纹被抹平**：超分对高频细节的处理可能直接擦掉真实缺陷 → FN 上升。
3. **延迟被忽略**：超分 4× 在 1280 图上的耗时可能数百 ms～数 s（CPU），端到端 P95 必须报告。
4. **"超分增加信息"幻觉**：超分不增加真实信息。AP 提升如果来自"超分让检测器更易见"，等价于分辨率提升，直接重训高分辨率更划算。
5. **训练时超分污染**：把超分 patch 当真实数据混入，模型学到超分纹理分布 → 域外崩。
6. **没有归因**：同时用超分+SAHI+高分辨率重训时，提升说不清是谁的。每次只开一个变量。
7. **推理设备假设**：演示笔记本 vs 训练 GPU 的超分速度差数量级；在目标设备上测。

## 六、评估指标与消融设计

- 主表：`全图直检 / SR+直检 / 目标区域SR+直检 / SR+SAHI` → mAP@0.5 / AP_S / P / R / 端到端 P95 / 峰值显存。
- 伪影审计：每配置人工看 ≥50 张超分输出，记录"新增伪边缘/抹平细纹"样本数。
- 决策结论：若 `SR 提升 AP_S 但 P95 超目标时延` 或 `提升不足 0.02`，结论写"超分预处理在本设备上不可行/不划算"，这也是有价值的负结果。

## 七、论文写法

可写：

> 超分预处理（2×）使 AP_S 提升 Δ，但端到端时延 P95 增加至 Y ms，超过部署目标；因此采用高分辨率重训/切片作为小目标主方案。

禁写：`超分提升了检测泛化`（无域外证据）、`超分弥补了小目标信息缺失`（不增加真实信息）、无时延的超分结论。

## 八、诚实自评锚点

- **可交付**：小实验 + 端到端时延 + 伪影审计 + 与 SAHI/重训的对比表。
- **部分完成**：小实验未提升 → 直接报告"超分预处理在本数据集上无效"，停止投入。
- **不可声称**：泛化提升、跨设备时延、训练侧超分的收益（未审计）。
- **停止线**：无法在目标设备测时延、或伪影无法审计时，停止该路线。
