# A4-01 小目标增强·SAHI 切片推理：精度与延迟的诚实权衡

> 本模块第一篇。**在固定候选模型（A2 选型结果）上，把 SAHI 切片推理作为推理侧消融，量化"AP_S 提升 Δ"与"端到端时延增加 Y"两个方向。**
> 前置：A2-01/02 的最终候选权重；A2-03 的尺寸分档。证据层 L3。

## 〇、前置判断

SAHI 是**推理侧**技术：大图切成带重叠的小块分别推理再合并，让小目标在切片里"变大"。它不改训练，只换推理协议。因此它适用于**测试/部署阶段**的性能提升，但如果只在 test 上用 SAHI 而训练时不用，模型没在切片分布上见过——提升可能有限且不稳定。真正稳定的做法是"训练时也用切片增强 + 推理时切片"，两份成本都要算。

## 一、问题严格定义

- 输入：原图（如 1280×n），候选检测模型，切片参数 $$(s_w, s_h, \mathrm{overlap}, \mathrm{nms})$$。
- 输出：合并后的全图检测结果；对比"全图推理"与"切片推理"的 mAP@0.5、AP_S/M/L 与端到端时延。
- 边界：切片参数属于部署超参，只能在 **val** 上选；test 只评一次。

## 二、该做什么

1. 装 `sahi`（切片推理工具库，GitHub: obss/sahi；用官方文档的 API，别手写切片合并）。
2. 参数网格：切片 512/640，overlap 20/33/50%，NMS IoU 0.3/0.5；在 val 上选一组。
3. 报告每档：mAP@0.5、AP_S、端到端时延 P50/P95/P99、FPS、显存。
4. 与"切片增强训练"对照：若训练时加切片增强，重训一个候选再测。
5. 输出决策表：哪些档位值得用 SAHI（AP_S 提升 ≥0.02 且 P95 可接受）。

## 三、技术方案

```python
from sahi import AutoDetectionModel
from sahi.predict import get_sliced_prediction

model = AutoDetectionModel.from_pretrained(
    model_type='ultralytics',
    model_path='weights/best.onnx',
    confidence_threshold=0.25, image_size=640)
result = get_sliced_prediction(
    image_path, model,
    slice_height=512, slice_width=512,
    overlap_height_ratio=0.33, overlap_width_ratio=0.33,
    postprocess_match_threshold=0.5)
```

- 合并后处理：跨片重叠目标用匹配 NMS 合并；class-agnostic NMS 时避免不同类别框互相吞。
- 成本口径：切片数 ≈ 全图面积/(切片面积×(1-overlap)²)；记录实际切片数与推理耗时。

## 四、数据层

- 评估数据：A1-01 锁定 test + A2-03 尺寸分档。
- 不新增训练数据；若做训练侧切片增强，用同一锁定 split 重训。

## 五、可能踩的坑

1. **切片把目标切两半**：边界处目标被裁，预测框中心不在片内或置信度崩。overlap 必须 ≥ 最大目标尺寸，否则无效。
2. **切片太小丢上下文**：叶片局部特写在 320 切片里看不清，背景信息缺失导致误检。切片不能无限小。
3. **在 test 上反复调参**：切片参数、NMS 阈值是超参，必须在 val 选一次。
4. **只报精度不报时延**：SAHI 端到端可能慢 3–10 倍。论文必须同时给"提升"与"代价"。
5. **训练/推理协议不一致**：训练 1280 全图、推理 512 切片，模型在尺度上没对齐。要么训练时也切片，要么明说这是"推理侧外推"。
6. **把 SAHI 提升说成模型提升**：SAHI 提升属于推理协议改进，模型本身没变。论文措辞要分开。
7. **显存假设**：切片推理可以小 batch，但逐片前向也有显存需求；在目标设备上测，别用训练机数字。

## 六、评估指标与消融设计

- 主表：全图 vs 切片（每档）→ mAP@0.5 / AP_S/M/L / P95 / FPS / 切片数。
- 消融：无 SAHI 训练 vs SAHI 训练+切片推理 vs 仅切片推理；每格 N。
- 结论模板：`在固定候选模型上，切片推理使 AP_S 提升 Δ，端到端 P95 由 X→Y`。

## 七、论文写法

可写：

> 切片推理（slice 512, overlap 0.33）在固定模型上使 AP_S 提升 Δ，但端到端时延为全图推理的 K 倍。

禁写：`SAHI 提升了模型能力`（是推理协议）、`小目标问题已解决`、无时延数据的切片结论。

## 八、诚实自评锚点

- **可交付**：val 上选参记录 + test 单次评估 + 时延对比表。
- **部分完成**：只测了推理未测训练侧 → 只报推理侧结果。
- **不可声称**：训练侧切片增强的收益（未重训）、跨设备时延外推。
- **停止线**：无法在目标设备测时延、或参数在 val 上未冻结时，停止 SAHI 结论。
