# C1-02 无编码器舵机的误差模型与不确定度传播：怎么从实测推广到"给论文的数字"

> 本模块第二篇。**SG90 没有编码器，位置信息只能来自"命令角度 + 误差模型"。本文把 C1-01 的实测散布变成一个可用的误差模型，并推演它在完整感知-执行链路里如何传播（含位姿/云台指向），以及论文里"不确定度"到底该写什么。**
> 证据层 L2 实测 + L4 参数化推演。

## 〇、前置判断

开环舵机的本质：**我们不知道舵机在哪，只知道我们命令它去哪**。因此系统对位置的所有置信，都来自 (a) 出厂标定（可能很差）和 (b) 我们自己的重复性实测。误差模型的价值是把"实测的散布"翻译成"链路端的不确定度"，让论文的每个数字都有边界。但它**不能**把开环变闭环——要真闭环必须加编码器（那属于工业迁移，见 C2-02）。

## 一、问题严格定义

- 模型：实测角 $$\theta = \theta_{cmd} + \epsilon_{sys}(\theta_{cmd}) + \epsilon_{rep}$$，其中 $$\epsilon_{sys}$$ 为系统偏差（来自 C1-01 的 $$e_{kin}$$），$$\epsilon_{rep}\sim\mathcal{N}(0,\sigma_{rep}^2)$$。
- 工程目标：给定一个使用场景（云台指向目标、叶片偏转角、需要对准的传感器），给出该场景下的位置不确定度 $$\sigma_\theta$$ 及 95% 区间。
- 链路传播：$$\theta \xrightarrow{\text{几何}} p$$（末端位置）→ 若用于对准，$$\sigma_p \approx |\partial p/\partial \theta| \cdot \sigma_\theta$$（一阶传播）。

## 二、该做什么

1. 用 C1-01 数据拟合 $$\epsilon_{sys}(\theta_{cmd})$$（多项式或查表）+ $$\sigma_{rep}$$（可做负载/方向条件相关）。
2. 对目标使用场景列出几何关系（云台臂长、叶片半径、偏转轴），算 $$\partial p/\partial \theta$$。
3. 蒙特卡洛传播：从实测分布采样 10⁴ 次，得 $$\sigma_p$$ 与 95% 区间（比一阶传播更诚实，尤其非线性几何时）。
4. 输出不确定度报告：场景、条件、$$\sigma_\theta$$、$$\sigma_p$$、95% 区间、假设清单。
5. 对论文：给出"本演示平台位置不确定度的可声明上界"。

## 三、技术方案（要点）

```python
import numpy as np
# 从 C1-01 实测拟合: eps_sys(theta), sigma_rep(theta, load)
def sample_theta(theta_cmd, n=10_000, rng=None):
    e_sys = eps_sys_fn(theta_cmd)                 # 查表/多项式
    e_rep = rng.normal(0, sigma_rep_fn(theta_cmd), n)
    return theta_cmd + e_sys + e_rep

# 场景几何: 末端位置 p = L * sin(theta) 之类
def p_of(theta): return L * np.sin(np.deg2rad(theta))
th = sample_theta(45.0)
p = p_of(th)
print(np.percentile(p, [2.5, 50, 97.5]))          # 95% 区间
```

- 一阶传播仅在 $$\theta$$ 变化小时可用；大角度/非线性用蒙特卡洛。
- 条件依赖：负载、方向、趋近速度——每个条件一个 $$\sigma_{rep}$$ 表，别用一个全局 σ。
- 输出单位：角度用度，位置用 mm；95% 区间按实际链路需求写。

## 五、可能踩的坑

1. **把 σ 当成精确值**：σ 本身有估计误差（N=30 的 σ 也有 ±20% 浮动）。报告给"上限"，别给点估计假装精确。
2. **忽略系统偏差**：只传播随机项，把 $$e_{kin}$$ 当 0——标定残差是恒定偏移，链路里会整体偏。
3. **全局 σ**：不同负载/方向 σ 差 2 倍，用一个数会高估或低估。条件表必须分。
4. **几何关系错误**：$$\partial p/\partial \theta$$ 算错（臂长、转轴位置）→ 位置不确定度差量级。先画图再算。
5. **一阶传播在非线性区失效**：大角度时 $$\sin\theta$$ 非线性，一阶泰勒展开低估真实区间。用蒙特卡洛。
6. **论文写"±0.5°"**：没有说明 95%/1σ/条件，等于没写。规范：`95% 区间、负载条件、N、测量系统分辨率` 四要素齐。
7. **把开环误差模型说成闭环控制**：模型只是"已知误差界"，不是反馈校正。论文用词注意。

## 六、评估指标与消融设计

- 输出：各场景的 $$\sigma_\theta$$、$$\sigma_p$$、95% 区间表。
- 消融：蒙特卡洛 vs 一阶传播的差异（验证线性近似何时失效）；条件相关 σ 表 vs 全局 σ 的区间差异。
- 结论模板：`在典型负载与正向趋近下，云台指向角 95% 区间为 X°，对应末端位置 ±Y mm`。

## 七、论文写法

可写：

> 采用开环舵机时，系统位置不确定度主要来自重复性（σ=…，95% 区间 …）与标定残差（…）；该上界小于/大于感知模块的分辨率，因此（不）构成系统瓶颈。

禁写：`舵机定位高精度`、无四要素的单个角度数字、把误差模型说成闭环校正。

## 八、诚实自评锚点

- **可交付**：误差模型 + 蒙特卡洛传播脚本 + 条件 σ 表 + 95% 区间报告。
- **部分完成**：只有静态条件表 → 动态条件（斜坡、阶跃、受风 B1）另表，论文注明适用范围。
- **不可声称**：闭环精度、跨批次一致性（不同批次 SG90 一致性需另测）。
- **停止线**：$$e_{kin}$$ 未分离、或场景几何未验证时，停止不确定度结论。
