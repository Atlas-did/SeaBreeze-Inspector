# C1-01 SG90 开环舵机重复定位实测与误差分解：三源分离协议

> 本模块第一篇。**SG90 是开环舵机（无编码器、无闭环），"精度"必须拆成三个来源分别测、分别报，否则一个总数字没法指导论文结论。**
> 证据层 L2（台架实测）+ L4（参数化推演）。

## 〇、前置判断

SG90 的"定位误差"不是一个数。它至少是三层叠加：**(a) 运动学残差**（从舵机命令角度到末端实际角度的映射误差）、**(b) 视觉测量不确定度**（我们靠相机读角度，读数本身有误差）、**(c) 物理重复性**（同一命令重复 N 次，落点散布）。把三者混在一个 RMSE 里，读者无法判断"是舵机不行还是测量不行"。本方案把三者拆开。

## 一、问题严格定义

- 命令：PWM 脉宽（如 500–2500 µs，90° 行程），或换算后的目标角度 $$\theta_{cmd}$$。
- 实测：相机/角度传感器读回实际角度 $$\theta_{obs}$$；真值基准用高分辨率角度编码器或激光线投影（精度至少比 SG90 重复性高一个量级，否则测不出来）。
- 三个待分离量：
  1. **运动学残差** $$e_{kin}=\bar{\theta}_{obs}-\theta_{cmd}$$（系统偏差，多为 PWM→角度标定的线性残差）；
  2. **测量不确定度** $$u_{meas}$$：同一静态角度重复读 N 次的读数散布（这是测量系统贡献，不是舵机贡献）；
  3. **物理重复性** $$u_{rep}=\sigma(\theta_{obs})$$ 扣除测量不确定度后的散布。
- 输出：每个命令角度的 $$\bar{e}_{kin}$$、$$u_{meas}$$、$$u_{rep}$$，以及端到端总误差 $$e_{tot}=\theta_{obs}-\theta_{cmd}$$。

## 二、该做什么

1. 搭台架：舵机固定、负载已知（Tello 上真实叶片或等效惯量盘）、标记点朝向相机、标定相机坐标系与舵机转轴对齐。
2. 标定 PWM→角度：多点（≥7 个角度，覆盖 90° 行程）线性/分段拟合，记录拟合残差——这一步决定 $$e_{kin}$$。
3. 三阶段测量协议：
   - **静态重复性**：同一 $$\theta_{cmd}$$ 反复 30–50 次，每次回到同一方向趋近（单侧趋近，消除反向间隙），记散布；
   - **反向间隙**：从 + 方向和 − 方向各趋近同一角度，记差值（间隙直接进入 $$u_{rep}$$）；
   - **方向相关性**：正向到达 vs 反向到达的角度差。
4. 数据落盘：`c1_raw.csv`（命令、实测、方向、次数、时间戳）+ 处理脚本，全部可复现。

## 三、技术方案（要点）

- 命令合成：用定时器产生精确 PWM；建议先示波器确认脉宽与实际角度的单调性，防止 PWM 精度不够引入额外误差。
- 测量：若用相机，标定像素→角度（弧度/像素）；每点取 ROI 内边缘/质心，亚像素提取，重复读数统计。若用角度传感器，直接记录其分辨率。
- 统计口径：对每个 $$\theta_{cmd}$$ 计算 $$\mu,\sigma$$；总误差用 RMS 跨角度汇总，并给 95% 区间（N≥30）。
- 间隙测量：`Δ = θ(从正方向到达) − θ(从负方向到达)`，取绝对值均值。

## 四、数据层

- 数据来源：本项目台架实测（Tello/SG90 演示平台，L2）。
- 数据清单：c1_raw.csv、标定参数（PWM 拟合系数）、相机标定文件、测量脚本版本。
- 工业外推数据（仅作量级对照，不作结论）：SG90 官方数据手册额定力矩/死区；工业舵机/无刷云台规格书——检索时记录 URL 与日期，写入 `data_sources.csv`。

## 五、可能踩的坑

1. **测量分辨率不够**：SG90 重复性可能 ±1°–±2°，如果相机读数本身散布 ±3°，测出来的全是测量误差。必须先单独量化 $$u_{meas}$$。
2. **反向间隙被平均掉**：正反向混着采样，间隙被均值吃掉。必须分方向记录。
3. **负载变化没控制**：空载 vs 带叶片 vs 带风（B1 风场）惯量/力矩不同，重复性不同。每份报告注明负载工况。
4. **PWM 定时精度**：软件延时抖动直接造成命令误差，等价于测出一个假的 $$e_{kin}$$。
5. **标定过拟合**：7 个点拟合 5 阶多项式，训练残差小但泛化差。用低阶（线性/二次）+ 留一校验。
6. **把测量不确定度算进舵机误差**：论文里必须分开报，否则 reviewers 会问"你的测量系统分辨率多少"。
7. **小样本统计**：N<10 的 σ 不可靠。静态重复 N≥30。

## 六、评估指标与消融设计

- 主表：每个 $$\theta_{cmd}$$ 的 $$e_{kin}$$、$$u_{meas}$$、$$u_{rep}$$、$$e_{tot}$$（含 95% 区间）。
- 消融维度：负载（空载/惯量盘/带叶）、方向（正/反/间隙）、趋近速度（快/慢 PWM 斜坡）。
- 输出结论：`在 X 负载下，SG90 端到端定位误差 95% 区间为 ±Y°，其中重复性贡献 ±Z°`。

## 七、论文写法

可写：

> SG90 开环舵机在典型负载下重复定位误差 95% 区间为 ±2.1°，其中测量不确定度与反向间隙分别贡献……；该精度限制与 B1/B2 抗风/悬停结论的分辨率边界一致。

禁写：`定位精度为 ±0.5°`（无来源、无负载工况、无测量不确定度分离的单一数字）、`高精度舵机`（SG90 是低精度玩具级）、把测量系统分辨率冒充舵机精度。

## 八、诚实自评锚点

- **可交付**：三源分离的实测数据 + 统计 + 标定文件。
- **部分完成**：只测了静态未测动态（斜坡/阶跃）→ 论文写"静态重复性"，不写动态跟随精度。
- **不可声称**：工业级精度、闭环伺服行为（SG90 无编码器，见 C1-02）。
- **停止线**：测量不确定度未单独量化、或负载工况未记录时，停止任何"精度"结论。
