# B1-01 风扇风场设计与受控悬停对照（含试验协议与失败安全）

> 本模块第一篇。工业风扇制造受控扰动、风速仪实测、固定平面标定测相对漂移，产出多 run 统计对照；试验协议与失败安全写在同一份里。
> 证据层 L2。

## 〇、前置判断

室内风扇扰动 ≠ 海上风场（湍流结构、阵风频谱、风速量级都不同）。它能支撑"在受控风扇扰动下某配置相对漂移更小/恢复更快"，不能支撑"2–3 级海风稳定悬停"。风况以风速仪实测为准，写"风扇第几档"等于没写。

## 一、问题严格定义

- 因变量（每 run）：相对水平漂移 RMSE、95% 分位、姿态角 std、扰动到稳定恢复时间、异常中止率。
- 自变量：控制器（基线 PID / 前馈 PID / EKF 扰动观测）× 风况（静风/低/中/高）。
- 空间参考：地面标尺网格或 ArUco/棋盘格平面 + 固定俯视相机；无 RTK 就无绝对坐标。
- 样本量：每控制器 × 每风况 ≥10 次独立悬停，每次 30–60 s。

## 二、该做什么

1. 无风先跑 3 次：校验标定残差、遥测时间戳、视频可用性。
2. 每档在悬停位置用风速仪测 10 s 均值/std/最大值 → `wind.csv`。
3. 随机试验顺序（控制器交替），避免电池衰减偏置。
4. 每 run 保存：原始视频、telemetry、命令参数、风速、异常事件。
5. 每 run 出轨迹与指标；按独立 run 求均值、SD、95% CI。
6. 试验协议：`trial_protocol_v1.md` 预先声明剔除规则（电池 SOC 起<25%、风速超窗、标定失真），剔除必须记录原因。
7. 失败安全：状态机必须能进安全停机态；预演一次遥测中断/加载失败，确认 FSM 安全转移（D2 有端到端版本，这里验证安全态）。

## 三、技术方案

$$RMSE=\sqrt{\frac{1}{N}\sum_t(x_t^2+y_t^2)}, \qquad p95=\text{95% 分位的}\ \|(x_t,y_t)-(x_0,y_0)\|$$

- 相机标定（棋盘格）记录重投影误差；像素→米换算系数写死并验证；固定飞行高度。
- 试验目录：`experiments/hover/EXP-YYYY-NN/{raw,config,logs,reports}`。
- 可重复性：同一配置跨天复测一组，结果须在 CI 内。

## 四、数据层

- `telemetry.csv`：run_id, t_monotonic, x_m, y_m, roll, pitch, yaw, batt, mode。
- `wind.csv`：run_id, stage, v_mean, v_std, v_max, temp, humidity。
- `run_metadata.yaml`：起飞质量、SOC 起止、初始位置、风向、高度、异常事件、操作者。
- `trial_log.csv`：status(valid/excluded/aborted)、excluded_reason、abort_event。

## 五、可能踩的坑

1. 电池衰减系统性偏置 → 随机顺序 + 记录 SOC。
2. "风扇档位"冒充风况 → 必须实测。
3. 风扇近场湍流强且空间不均 → 记录风扇距离/位置。
4. 相机畸变未校正 → 边缘漂移被放大。
5. Tello 自身高度漂移放大像素→米误差 → 只报平面相对位移。
6. 把帧当独立样本 → 统计单位是 run。
7. 初始位置不一致 → 用固定起飞标记点。
8. 异常 run 静默删除 → 剔除必须预声明原因。
9. 安全围挡/急停缺失 → 不试飞。

## 六、评估指标与消融设计

- 主表：控制器 × 风况 → RMSE、p95、姿态 std、恢复时间、N、95% CI。
- 改善率同时给绝对数与比例：`RMSE 由 A 降至 B（Δ，95% CI，比例 X%）`。
- 消融：基线 PID / 前馈 / 前馈+EKF（一次只加一个组件）。
- 可区分性：两组 CI 不重叠才算"差异显著"，否则写"未观测到显著差异"。

## 七、论文写法

可写：`在受控风扇扰动（实测均值 X m/s，std Y）下，前馈+EKF 相对基线 PID 的相对平面漂移 RMSE 由 A 降至 B（N=…，95% CI）。`

禁写：`2–3 级海风稳定悬停`、`工业级抗风验证`、`±5 cm 绝对定位`。

## 八、诚实自评锚点

- **可交付**：风速实测 + 固定标定 + ≥10 run/格 + CI + 协议与剔除记录。
- **部分完成**：仅定性演示 → 撤下硬指标表。
- **不可声称**：海上风适应、绝对精度、工业平台有效性。
- **停止线**：风速不可实测、标定残差过大或安全设备缺失时停止。
