# B1-02 EKF 扰动观测与参数敏感性消融

> 本模块第二篇。把 Q/R 当作显式超参做敏感性消融，用风速仪验证"观测器看到的是扰动而不是噪声"。
> 前置：B1-01 试验协议与数据。证据层 L2。

## 〇、前置判断

EKF 在 Tello 上是趋势验证与机制演示。Q/R 调完不记录 = 论文里"EKF 有效"不可复现。观测器输出与真实风速的**相关性**是"观测到扰动"的关键证据。

## 一、问题严格定义

- 状态示例：$$x=[p_x,p_y,v_x,v_y,\hat d_x,\hat d_y]$$（位置、速度、估计外部扰动加速度）。
- 消融变量：Q（过程噪声）、R（观测噪声）、前馈增益 $$k_{ff}$$。
- 输出：各档下扰动追踪误差（相对风速仪）、悬停漂移、滤波器不发散。

## 二、该做什么

1. 仿真扫 Q/R 量级确定不发散范围；静风数据做无风基线（观测器应输出≈0）。
2. 选 3 组代表性 Q/R（保守/适中/激进），同风况随机顺序各 ≥10 run。
3. 同步风速仪时间序列，做时间对齐相关（考虑传输时延）。
4. 输出：每档漂移指标 + 观测-风速相关 + 滤波器诊断（新息均值、方差、协方差不发散）。

## 三、技术方案

- 外部风等效为加速度扰动 $$d(t)$$，状态含 $$d$$，输出 $$\hat d$$ 供前馈。
- 相关性：以风速仪 10 s 窗口均值对齐后算 $$\mathrm{corr}(\hat d, v_{wind})$$ 与滞后峰值；按 run 独立计算 95% CI。
- 诊断：新息均值≈0（无偏）、方差与 R 一致（不低估噪声）、协方差不发散。

## 四、数据层

- 复用 B1-01 的 telemetry/wind；新增 `ekf_diagnostics.csv`（run_id, t, innovation, P_diag）。
- 风速仪 ≥10 Hz，与遥测时间戳对齐；记录两系统时钟偏差。

## 五、可能踩的坑

1. 调参过拟合单次 run → 必须在 ≥10 run 统计。
2. 观测器把噪声当扰动 → 静风基线输出方差显著非零时，先修参数。
3. 时间不对齐就求相关 → 先互相关找滞后。
4. Q/R 拍脑袋 → 用静风段估计 R。
5. 仿真参数直接当台架参数 → 台架必须重标。
6. 滤波器发散被均值掩盖 → 报告新息/协方差。
7. 把"观测到等效扰动"说成"观测到风" → 措辞区分。

## 六、评估指标与消融设计

- 主表：Q/R 档 × {漂移 RMSE, p95, 恢复时间, 观测-风速相关, CI}。
- 消融：B / EKF(保守/适中/激进) / EKF+前馈。
- 负结果照写：激进 Q/R 导致抖动更差时，如实报告并解释（噪声放大的代价）。

## 七、论文写法

可写：`EKF 扰动观测器输出与实测风速相关为 r（滞后 τ，N=…），配合前馈后漂移 RMSE 降至……`

禁写：`EKF 精确估计外部风`、`工业飞控实现 EKF`（仓库只在 Tello 级演示）。

## 八、诚实自评锚点

- **可交付**：Q/R 消融 + 静风基线 + 相关分析 + 滤波器诊断。
- **部分完成**：只有仿真 → 结论止于仿真趋势。
- **不可声称**：风场精确估计、工业平台有效性。
- **停止线**：风速仪不可用或时间无法同步时停止。
