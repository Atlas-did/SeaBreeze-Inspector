# A1-02 类别不平衡与标签质量治理：加权、focal 与清洗的完整做法

> 本模块第二篇。承接 A1-01 的锁定 split；把"复制图片提分"科学化为三类手段：类别加权、focal loss、标签质量治理。
> 证据层 L3。

## 〇、前置判断

"复制少数类图片两倍"提分是真实现象，但它是三个问题的叠加：类别不平衡（→权重/focal）、样本质量差异（→重加权/清洗）、小目标（→copy-paste/切片，见 A4）。复制图片只改变 loss 权重，**不增加信息**，救不了小目标，重复过多会过拟合。

诚实估计：权重/focal 是"mAP@0.5 从 0.57753 往 0.70–0.78 走"的杠杆，不是冲 95% 的魔法。

## 一、问题严格定义

- 目标：不换模型、不增数据，靠训练侧加权与标签治理改善少数类与小样本的 P/R 与整体 mAP@0.5。
- 输入：A1-01 锁定 split；输出：若干组可比较训练配置 + 清洗报告。
- 度量：同一 test、同一阈值协议的 mAP@0.5 / R / F1。

## 二、该做什么

1. 统计 train 每类框数、每档尺寸实例数 → `class_stats.csv`（不靠目测）。
2. 冻结训练协议：seed=0、imgsz=1280、batch=8、epoch=200、增强同 v3。
3. 对照：B / B+类别权重 / B+focal(γ=2) / B+两者 / B+质量加权。
4. val 选一次最终配置，test 只评一次。
5. 标签治理：自动筛模糊/水印/非叶片图 + 每类抽 100 框人工复核 + 双人复标 200–500 张算一致率；删除项写 `cleaned_log.csv`（原因、reviewer、原哈希）。

## 三、技术方案

- 权重：ultralytics 默认按实例频率算 `cls_pw`，可显式关闭做对照。
- focal：通过 loss 增益参数调 γ；检测任务的 `copy_paste` 参数**不生效**（分割专属）。
- `train.py` 必须先扩展 `--model --project --name --seed --cls_pw`（现仓库固定 `yolov8n.pt`），禁止手工改同一文件丢记录。
- 质量加权：dataloader 用 `WeightedRandomSampler(q_i)` 或把质量分乘进分类损失；与类别加权正交，两者相乘需 clamp 上限防过拟合。
- 质量分组成：清晰度（Laplacian 方差/BRISQUE）、与 v3 预测框的启发式一致性、人工标记。**模型预测只能当候选，不能当最终裁决。**

## 四、数据层

- 复用 A1-01 锁定 split，不新增图像。公开数据不参与本组对照（会污染归因）。
- 负样本在治理后重新确认：被删图的空标签一并处理，防止空标签残留。

## 五、可能踩的坑

1. 复制过度 → 验证集先涨后跌；看 FN 分类而非只看 mAP。
2. 加权把 P 抬高但 R 掉 → 报告 P/R 权衡，不只报 mAP。
3. focal 加倍惩罚脏标签（脏标签本来就是难样本）→ 先清洗再 focal。
4. 四组 seed 不同 → 0.01–0.03 波动，对照不成立。
5. batch=8@1280 的 BN 统计噪声 → 保持 batch，加 `cache=true` 减少 IO 抖动。
6. val 反复选 → 隐式过拟合；选一次冻结。
7. 删除过度 → 样本不足；设最低保留数。
8. 双人复标标准漂移 → 写 `annotation_guideline_v1.md` 仲裁。

## 六、评估指标与消融设计

- 主表：每组 P/R/F1/mAP@0.5/mAP@0.5:0.95/每图耗时。
- 辅助：PR 曲线叠加、每类混淆矩阵、FN 根因分布对比、清洗前后对照、复标一致率 κ。
- 诚实归因：若 w+focal 相对 B 的 ΔmAP 落在 seed 噪声内（<0.01 且无 CI），写"未观测到显著改善"。

## 七、论文写法

可写：`在锁定测试集上，类别加权+focal(γ=2) 使 mAP@0.5 提升 Δ，主要来自 Recall（R 由 X→Y）；Precision 变化 Z。`

禁写：`加权后 95%`、`复制图片提升泛化`、在 test 上反复调参。

## 八、诚实自评锚点

- **可交付**：对照组 + 完整 args.yaml + PR 曲线 + FN 分类 + 清洗日志 + 一致率。
- **部分完成**：只跑了部分对照 → 只报已跑组。
- **不可声称**：加权提升小目标 AP（那是 A4）、单一参数归因（未消融）、test 上选阈值。
- **停止线**：类别统计表生成不了 → 回 A1-01 补审计。
