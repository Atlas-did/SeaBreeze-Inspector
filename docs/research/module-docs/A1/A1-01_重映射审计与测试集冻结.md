# A1-01 三分类→单类缺陷检测：重映射、数据审计、分组划分与测试集冻结

> 本模块第一篇（数据地基）。解决"从三分类标签到可答辩的二分类数据集"的完整链路。另一篇 A1-02 处理类别不平衡与标签质量。
> 证据层 L3（离线视觉评估）。

## 〇、前置判断

二分类不是新魔法，它把已核验的三分类缺陷框重新定义为单一类别并重训。真正的门槛是**数据**：没有锁定测试集、来源组划分和负样本策略之前，任何新 mAP 都不可信。

当前可核验基线（v3 训练包 results.csv 末行）：Precision 0.71545，Recall 0.51950，mAP@0.5 0.57753，mAP@0.5:0.95 0.34559。这是**三分类目标检测**的验证集数字，不是图像二分类 accuracy。

## 一、问题严格定义

- 输入：审计后的图像 + YOLO 标签（crack=0 / corrosion=1 / leading_edge_damage=2）。
- 输出：单类缺陷检测数据集（所有框类别 ID=0）+ 锁定 test 集 + 可追溯 manifest。
- 必须区分两件事：
  1. **单类目标检测**：一图多框仍保留多框，全部映射为 `defect`；主指标 mAP/P/R/F1。
  2. **图像级二分类**：整图"有缺陷/无缺陷"；是另一任务，需独立标签与评估，不得与检测 mAP 混报。
- 失败条件：标签类别越界、归一化坐标越界、零面积框、空标签但图内确有目标。

## 二、该做什么

1. 建立 `manifest.csv`（image_id, sha256, source_id, blade_id, flight_or_video_id, split, reviewer）。
2. 数据审计：缺图/缺标签、坐标越界、零面积框、重复哈希、异常宽高比、未知类别。
3. `remap_to_binary.py`：只改标签首列为 0，坐标原样；输出逐文件转换计数与错误日志。
4. **group split**（同一 source_id 只能进一个 split）70/15/15。
5. 锁定 test 集并打 SHA-256；此后 test 不参与阈值、增强、模型选择。
6. 负样本策略（见数据层）与人工复核。

## 三、技术方案

```python
def remap_labels(label_dir, out_dir, log_path):
    rows = []
    for lbl in sorted(label_dir.glob('*.txt')):
        lines = [l.split() for l in lbl.read_text().splitlines() if l.strip()]
        ok = []
        for toks in lines:
            cls = int(toks[0]); x, y, w, h = map(float, toks[1:5])
            assert cls in {0,1,2}, f'未知类别 {cls}'
            assert 0 < x < 1 and 0 < y < 1 and 0 < w < 1 and 0 < h < 1, f'越界 {toks}'
            assert w*h > 0, f'零面积 {toks}'
            ok.append(' '.join(['0', *toks[1:5]]))     # 仅类别置 0
        (out_dir/lbl.name).write_text('\n'.join(ok)+('\n' if ok else ''))
        rows.append((lbl.stem, len(lines), len(ok)))
    # 写 log：image, boxes_before, boxes_after —— 前后必须相等
```

- 数据 YAML 单类：`names: {0: defect}`。
- **禁止**把同图重叠框合并成一个大框（改变目标数量，污染 AP）。
- 负样本 = **空标签文件**；只有人工确认无缺陷的图才能当负样本。漏标图当负样本 = 把漏检当正确。

## 四、数据层

- 主数据：项目 13k 缺陷图 + 标签 + 拍摄批次（视频/叶片/日期）信息。
- 补充公开数据（仅预训练/扩展，不污染主 test）：检索 `wind turbine blade defect detection dataset`、`wind turbine crack corrosion dataset`，入口 [Kaggle Datasets](https://www.kaggle.com/datasets)、[Roboflow Universe](https://universe.roboflow.com/)；核验许可证、标注格式、来源组、水印。
- 负样本：从完整叶片扫描视频取**人工确认无缺陷**的帧；记录 reviewer。
- 全部来源写 `data_sources.csv`（URL、访问日期、许可证、SHA-256、域差异）。不核验许可的数据只作探索，不进主 test。

## 五、可能踩的坑

1. 类别 ID 与 `detect.py` 写死的 0/1/2 冲突 → 类别表从配置/权重读取。
2. 同图多框被工具误合并 → 转换后逐文件比对框数。
3. 空标签 ≠ 正常：漏标图当负样本 → Recall 假性虚高。
4. 同叶片/相邻帧跨 train/val → 指标虚高；必须 group split。
5. 越界/零面积框未被清洗 → ultralytics 静默裁剪或报错，日志看不出来。
6. 负样本比例失控 → 模型倾向空框或乱检；先在 val 扫 conf 看 PR 曲线。
7. 权重加载失败自动 mock → 演示必须 `mock=False`，失败即停。

## 六、评估指标与消融设计

- test 单次评估：P / R / F1 / mAP@0.5 / mAP@0.5:0.95 / 每类 AP / 每图耗时 P50/P95/P99。
- 图像级指标（辅助任务，单列一表）：accuracy、图像级混淆矩阵——不与检测 mAP 同格。
- 消融：v3 三分类（原 task）vs 单类检测（新 task），表头注明"任务不同不可直接比较"。
- FN 根因分析输出 `fn_taxonomy.csv`（极小/低对比/遮挡/模糊/标注/背景/NMS/置信度）。

## 七、论文写法

可写：`在按来源组划分并锁定的测试集上，单类缺陷检测 mAP@0.5=X、Recall=Y（N 图像，M 框）。`

禁写：`缺陷检测准确率 95%`（未定义指标与 test）、把二分类 mAP 与三分类 mAP 直接比较、`已实现海上缺陷检测`。

## 八、诚实自评锚点

- **可交付**：重映射脚本通过、manifest 完整、test 锁定、两套权重在同一锁定 test 并列报告。
- **部分完成**：只有 v3 数字 → 只报 v3 基线。
- **不可声称**：二分类优于三分类（未同任务比）、图像级 accuracy 与检测 mAP 混报。
- **停止线**：无原始标签/批次信息 → 退回到按目录近似分组并声明粒度。
