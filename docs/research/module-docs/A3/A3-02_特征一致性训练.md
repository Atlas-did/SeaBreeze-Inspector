# A3-02 特征一致性训练：雾不变表征（主路线，含评审修正版）

> 本模块第二篇（本文方法）。**不学"怎么把雾擦掉"，学"不管有没有雾，都提取出相同的任务特征"；推理零额外开销。本版吸收样本文档自带的评审修正（§12）。**
> 前置：A3-01 配对数据 + 不可见标记。证据层 L3。

## 〇、前置判断

特征一致性优于"先像素级去雾再检测"的原因：不需要像素级 clean 真值、不引入去雾延迟与伪影、推理时无额外网络。但**它不是万能**：它不解决小目标（那是 A4）、不解决镜头盐晶附着（那是硬件/物理）、不消除真实海雾与合成雾的域偏移（那要域外数据）。且按评审修正，检测任务的"输出一致性损失"不成立，只能做 backbone 特征一致性。

## 一、问题严格定义

- 符号：$$I_c$$ clean；$$I_f$$ fog（由 $$I_c$$ 合成）；$$E(\cdot)$$ backbone 编码器；$$z_c=E(I_c)$$，$$z_f=E(I_f)$$；$$\mathrm{proj}(\cdot)$$ 投影头（2 层 MLP，输出 128–256 维）；任务头 $$D$$（检测头）或 $$H$$（回归头）。
- 目标：$$\|\mathrm{proj}(z_f) - \mathrm{proj}(z_c)\|$$ 尽量小，同时检测/回归任务损失不退化。
- 任务边界：
  - **检测版（接现有 YOLO）**：只加 backbone 特征一致性损失 $$\mathcal{L}_{feat}$$；**不做**输出一致性（检测头是分类 logits+框+置信度的异构张量，clean/fog 的 anchor 不一定匹配，强对齐会破坏训练）。
  - **回归版（面向控制）**：才可同时用 $$\mathcal{L}_{state}$$ + $$\mathcal{L}_{cons}$$ + $$\mathcal{L}_{feat}$$。

## 二、该做什么

1. 冻结 A3-01 配对集与不可见标记；每 batch 内 clean:fog = 1:1，同一 clean 的 fog 变体尽量不重复。
2. 在 ultralytics 上加一个训练期辅助分支：backbone 的 P3/P4/P5 各接 1×1 conv + 投影头，$$\mathcal{L}_{feat}$$ 取三层之和。
3. 训练协议：Stage 1 大 $$\lambda_3$$（前 10–20 epoch），随后 cosine 退火；不做"冻结任务头"的两阶段（会 feature-head mismatch）。
4. 不可见样本：`invisible_flag=1` 的 fog 图关闭检测损失，只留 $$\mathcal{L}_{feat}$$（或整体降权）。
5. 评估：雾鲁棒性曲线 + 特征一致性分数 + 与去雾 baseline（A3-03）同表对比。

## 三、技术方案

检测版损失：

$$\mathcal{L} = \mathcal{L}_{yolo}(I_c) + \mathcal{L}_{yolo}(I_f)\,\mathbb{1}_{\text{visible}} + \lambda_{feat}\, \sum_{p\in\{P3,P4,P5\}} \big\|\mathrm{proj}_p(z_f^{(p)}) - \mathrm{proj}_p(z_c^{(p)})\big\|_1$$

回归版损失（若做）：

$$\mathcal{L} = \lambda_1\underbrace{\left(\|p_c-p^*\|_2^2 + \|p_f-p^*\|_2^2\right)}_{\mathcal{L}_{state}} + \lambda_2\underbrace{\|p_f-p_c\|_1}_{\mathcal{L}_{cons}} + \lambda_3\underbrace{\|\mathrm{proj}(z_f)-\mathrm{proj}(z_c)\|_1}_{\mathcal{L}_{feat}}$$

- 角度回归必须用 $$\sin/\cos$$ 双通道（6 维替 3 维），否则 359° 与 1° 的 MSE 算成 358²。
- **防塌缩**：单卡 batch=16 下 InfoNCE 负样本太少。用 BYOL/SimSiam（stop-gradient + predictor），或把一致性目标压在投影头输出上并加 L2 归一化。
- $$\lambda$$ 建议：$$\lambda_1=1.0,\ \lambda_2=0.5,\ \lambda_3$$ 初始 0.3，cosine 退火到 0.05（把 schedule 写进 config，而不是"后期退火到 0"这种模糊描述）。
- 多尺度：小目标信息在浅层 P3，$$\mathcal{L}_{feat}$$ 三层求和可调权重（P3 更大）。
- 无真值退化版：去掉 $$\mathcal{L}_{state}$$，$$\mathcal{L}_{cons}$$ 提到 1.0（回归版）或纯特征一致性（检测版）。

## 四、数据层

- 训练/验证 = A3-01 配对集；同一 clean 的所有 fog 变体整组进同一 split。
- 不掺公开雾数据训练（域外数据只作评估）。
- 若要做域外微调（真实雾图），需单独声明：新增数据、标注来源、许可证、仅用于 final fine-tune 并单独测。

## 五、可能踩的坑

1. **表征塌缩**：投影头输出全部塌到一个点，$$\mathcal{L}_{feat}\to0$$ 但任务损失崩。用 stop-grad + predictor + 余弦距离，训练中盯投影输出的方差/std。
2. **feature-head mismatch**：先冻结任务头只训投影头，解冻后特征分布变了。改联合训练 + 前 10 epoch 大 $$\lambda_3$$。
3. **batch 内同 clean 多变体**：一张 clean 配 4 种 fog 时，batch=16 的有效独立 clean 只有 4 张，BN 与梯度方差大。batch 内尽量 clean 不重复；或用 memory bank 跨 batch 取负（BYOL 不需要）。
4. **不可见目标硬训**：浓雾下目标消失还要求框 = 喂噪声。按 `invisible_flag` 关闭 $$\mathcal{L}_{yolo}(I_f)$$。
5. **检测输出一致性损失**：不要做。detection head 输出尺度相差数量级，clean/fog anchor 不对齐，硬对齐会把训练弄崩（样本文档 §12 已修正）。
6. **角度回归周期性**：回归版直接回归欧拉角会崩；用 sin/cos 双通道。
7. **$$\lambda_3$$ 过大**：特征一致性压过任务损失，模型只学"和 clean 一样"而忘了"检出缺陷"。退火 schedule 必须写进配置。
8. **在 val 上反复调 $$\lambda$$**：λ 也是超参，只能在 val 上调一次并冻结；test 只评一次。

## 六、评估指标与消融设计

- 主表：每个 $$\beta$$ 档的 mAP@0.5 / P / R（含 clean 档）；横轴 $$\beta$$，纵轴 mAP 的"雾鲁棒性曲线"。
- 特征一致性分数：$$\|\mathrm{proj}(z_f)-\mathrm{proj}(z_c)\|_2$$ 训练前后对比。
- FN 随 $$\beta$$ 的增长率（漏检是雾攻击的主要形态）。
- 消融：B（无一致性）／B+$$\mathcal{L}_{feat}$$(仅P3)／B+$$\mathcal{L}_{feat}$$(P3+P4+P5)／B+$$\mathcal{L}_{feat}$$+不可见降权。每格给 N 与置信区间。
- 对比行：A3-03 去雾路线在同一测试协议下的结果。

## 七、论文写法

可写：

> 在合成海雾扰动集上，特征一致性训练使 mAP@0.5 从 β=1.5 档的 X 恢复到 Y，且推理端到端时延与基线一致（零额外网络开销）。

禁写：`模型已适应真实海雾`（只有合成扰动证据）、`特征一致性解决小目标`、把不可见样本的检测损失关闭说成"鲁棒性提升"而不报不可见比例。

## 八、诚实自评锚点

- **可交付**：配对数据可复现 + 雾鲁棒性曲线 + 消融表 + λ schedule 入档。
- **部分完成**：只有合成雾证据 → 结论止于"合成扰动条件下"；若域外真实雾测试失败，明写"外推失败，真实海雾待数据"。
- **不可声称**：海上实测抗雾、像素级恢复能力、控制稳定性收益（除非跑了回归版 + 受控试验）。
- **停止线**：配对数据不可复现、投影头方差监测缺失、或不可见样本处理未定义时，停止结论扩展。
