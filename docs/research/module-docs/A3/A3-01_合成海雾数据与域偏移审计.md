# A3-01 合成海雾数据与域偏移审计：配对数据集的构建纪律

> 本模块第一篇（数据地基）。**特征一致性路线（A3-02）与去雾路线（A3-03）共用这份合成数据；先证明"合成雾可信、clean 可信、配对关系可复现"，再谈训练。**
> 证据层 L3（合成扰动鲁棒性）。

## 〇、前置判断

"配对数据不需要真实拍摄"是对的——在干净图上加雾天然得到 (clean, fog) 一一配对，视角、时刻、内容完全一致。但**"免费"不等于"有效"**：合成雾 ≠ 真实海雾/盐雾，二者在光谱、空间分布、粒子尺寸、镜头盐晶附着、运动模糊耦合上都有系统性差异。合成数据能支撑的结论是"在定义好的合成扰动协议下模型更鲁棒"，**不能**支撑"已适应真实海上盐雾"。

## 一、问题严格定义

大气散射模型（ASM / Koschmieder）：

$$I(x) = J(x)\cdot t(x) + A\big(1-t(x)\big), \qquad t(x) = \exp(-\beta\, d(x))$$

- $$J$$：clean 图；$$A$$：大气光（海雾建议灰偏蓝，如 $$(0.70, 0.75, 0.82)$$）；$$\beta$$：散射系数（雾浓度）；$$d(x)$$：逐像素深度。
- 三类合成策略：
  1. **均匀雾**：$$t=\mathrm{const}$$（无深度可用时）；
  2. **伪深度雾**：用高斯/斜面/图像亮度估计伪深度做空间渐变，写明"伪深度"假设；
  3. **真深度雾**：已有单目深度估计输出时用其做渐变雾（声明深度模型及其误差）。
- 配对定义：一个 `pairs.csv` 行 = `clean_path, fog_path, beta, degrade_type, seed, invisible_flag`。
- 域差异维度必须书面列出：海雾偏蓝偏湿、粒子更大导致散射非均匀、真实镜头盐晶附着（本方案**不做**，属于 C1/D3）、雾与运动模糊同时存在（耦合扰动，另见 D1）。

## 二、该做什么

1. **clean 源审计**：现有 13k 缺陷图**不能直接当 clean**——里面可能本来就有雾/过曝/脏图。先用清晰度筛选（Laplacian 方差、BRISQUE）与人工抽查，只留清晰度合格图进 clean 池。
2. 写合成器（见技术方案），生成多档 $$\beta$$，逐档保存原图、参数、种子。
3. 逐样本计算"雾后目标可见性"：目标区域在 fog 图上的对比度（边缘响应或局部对比度）低于阈值 → 标 `invisible_flag=1`。
4. 域审计：定量（雾浓度估计、对比度分布、no-reference 质量分）+ 定性（人工看图册）。
5. 固定数据版本：pairs.csv 打 SHA-256，写入 manifest，之后不再追加改动。

## 三、技术方案

```python
import numpy as np

def add_fog(img, A=(0.70, 0.75, 0.82), beta=1.0, depth=None, seed=0):
    h, w = img.shape[:2]
    if depth is None:
        t = np.full((h, w), np.exp(-beta * 0.5))   # 0.5 是"假设平均深度"，必须注释
    else:
        t = np.exp(-beta * depth)
    t = np.clip(t, 0.05, 1.0)[..., None]
    return (img.astype(np.float32) * t + np.array(A) * (1 - t)).astype(np.uint8)
```

- $$\beta$$ 档位建议：`{0.25, 0.5, 1.0, 1.5, 2.0}`，对应轻雾→浓雾；至少包含 4 档才画得出"雾鲁棒性曲线"。
- 可见性判定（示例）：取目标框内像素与框外邻域的背景对比度（如平均绝对差 / 边缘响应），低于阈值 $$\tau$$ 记不可见；$$\tau$$ 在写代码时冻结并写入 `config/fog_config.yaml`。
- 输出目录：

```
data/paired/
├── clean/            # 仅清晰度合格图
├── fog_b025/ fog_b05/ fog_b10/ fog_b15/ fog_b20/
├── pairs.csv         # clean_path, fog_path, beta, degrade_type, seed, invisible_flag
└── labels/           # 与 clean 对齐的检测标签（原样复制）
```

## 四、数据层

- 主数据：项目 13k 缺陷图中经清晰度筛选的子集。
- 公开域外数据（只做 sanity check，**不参与训练**，不进入主 test）：
  - 合成雾场景：检索 `RESIDE OTS`、`Foggy Cityscapes`；
  - 真实雾场景：检索 `RESIDE ITS`、`RTTS`、`DENSE fog dataset`；
  - 海事/海上：检索 `SeaDronesSee`、`marine object detection fog`。
  - 每条数据写入 `data_sources.csv`：URL、许可证、版本、下载 SHA-256、是否真实采集、标注格式。
- 域外数据的作用：在训练完成后跑一次，看合成雾学到的鲁棒性**能否外推到真实雾**。外推失败是正常结果，如实报告并把它当作"合成扰动研究"的边界证据。

## 五、可能踩的坑

1. **把本来有雾的图当 clean**：合成 fog 叠在真雾上，配对关系失真，训练出的"一致性"实际对齐的是两层雾的叠加。必须先行清晰度筛选。
2. **$$\beta$$ 过大目标客观消失仍要求检测框**：目标区域对比度趋近于零，原框在 fog 图上无信息。此时若还喂检测损失 = 喂噪声。必须用 `invisible_flag` 关闭或降权（见 A3-02）。
3. **灰雾 vs 海雾偏蓝**：把 $$A$$ 设成纯灰会让模型对海雾色彩不敏感；用偏蓝 $$A$$ 时要在论文里写清楚是"海雾近似"。
4. **伪深度与相机几何不符**：用斜面/高斯伪深度时，雾的空间分布与真实距离无关，属于"风格化扰动"而非物理模拟；论文里写"基于伪深度的空间渐变雾"。
5. **同 clean 生成多变体泄漏**：同一 clean 的 4 个 fog 变体若跨 train/val 分布，指标虚高。变体必须整组待在同一个 split（以 clean 为分组单位）。
6. **合成参数不可复现**：seed、$$\beta$$、$$A$$、depth 来源都要入档，否则"每张合成图可由原图 ID 和参数复现"的承诺落空。
7. **混合多种扰动时无法归因**：雾+盐粒+模糊一起加，指标掉了说不清是谁的贡献。分开生成、分开评估，再谈叠加。

## 六、评估指标与消融设计

- 域审计输出：各 $$\beta$$ 档的对比度分布直方图、no-reference 质量分（如 BRISQUE）统计、人工看图册（每档 ≥20 张）。
- 数据层指标：`invisible_flag` 比例随 $$\beta$$ 的曲线（浓雾下多少目标不可见，直接决定"该关哪档检测损失"）。
- 消融（留给 A3-02/03）：同一模型在 clean-only、clean+单档雾、clean+多档雾上的 mAP 衰减曲线。

## 七、论文写法

可写：

> 基于大气散射模型生成四档合成海雾扰动（β∈{0.5,…,2.0}），全部样本可由原图、参数与随机种子复现；雾后目标区域对比度低于阈值的样本标记为不可见并从检测监督中降权。

禁写：`合成雾等同真实海雾`、`已适应海上盐雾`、`13k 图全部为清晰 clean 样本`（未筛选前不许这么说）。

## 八、诚实自评锚点

- **可交付**：pairs.csv + 清晰度筛选记录 + 不可见统计 + 域审计报告，全部可复现。
- **部分完成**：只有均匀雾无渐变雾 → 论文写"均匀大气散射合成"，不写空间渐变。
- **不可声称**：真实海雾适配（无域外实测或仅域外测试失败）、盐雾镜头效应（未建模）。
- **停止线**：clean 源未过清晰度筛选、或 pairs.csv 无法复现（缺 seed/参数）时，停止后续训练结论。
