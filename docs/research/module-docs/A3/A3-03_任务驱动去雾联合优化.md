# A3-03 任务驱动去雾与检测联合优化：作为互斥 Baseline 的完整实现

> 本模块第三篇（对照 Baseline）。**"先去雾再检测"是与特征一致性（A3-02）互斥的路线，作为论文 Baseline 出现，不是叠加模块。本方案实现"任务驱动"的去雾——去雾网络由检测损失监督，而不是追求像素级还原。**
> 前置：A3-01 配对数据。证据层 L3。

## 〇、前置判断

去雾路线有两个版本，必须分清：

1. **级联**：先去雾 $$\hat{J}=G(I_f)$$，再送检测器；两段独立训练/评估。实现简单，但去雾误差直接放大进检测，且推理延迟翻倍。
2. **联合（任务驱动）**：去雾网络与检测头端到端训练，检测损失反传进去雾网络。去雾网络学的是"让检测器更好"，而不是"像素级还原干净图"。

本方案选**联合 + 任务驱动**作为与特征一致性可比的正牌 Baseline：二者都用 A3-01 的配对数据、同一检测器、同一评估协议，唯一差别是"雾处理在网络前面做"还是"在特征里做"。论文结论必须诚实：若任务驱动去雾在延迟代价下没有显著优势，那恰恰是特征一致性路线的论据，不是缺陷。

## 一、问题严格定义

- 输入：$$I_f$$（雾图）与配对 $$I_c$$（仅训练时用）。
- 级联：$$\hat{J}=G(I_f)\to D(\hat{J})\to\{框,类,置信\}$$。
- 联合：$$\mathcal{L}_{total} = \mathcal{L}_{yolo}(D(G(I_f))) + \lambda_r \mathcal{L}_{recon} + \lambda_t \mathcal{L}_{tv}$$，其中 $$\mathcal{L}_{recon}$$ 可选（L1 到 $$I_c$$），$$\lambda_r$$ 控制"任务驱动 vs 像素还原"的平衡。
- 明确目标：检测指标（mAP/P/R）为准；$$\hat{J}$$ 的观感质量只是辅助。

## 二、该做什么

1. 选轻量去雾网：建议参数量 <2M 的传输估计型结构（估计 $$t(x),A$$ 再重建），避免大模型抢走推理预算。
2. 联合训练：检测头用冻结的 A2-01 预训练权重初始化；去雾网随机初始化；$$\lambda_r$$ 从 0 到 0.1 扫描（val 上选一次）。
3. 在 A3-01 的 $$\beta$$ 档上做雾鲁棒性曲线，与 A3-02 同表。
4. 端到端时延：去雾前向 + 检测前向，P50/P95/P99，与"仅检测"对比。
5. 伪影审计：去雾输出上因过平滑/halo 产生的检测 FN，单独统计。

## 三、技术方案

- 级联基线（最简单）：现成轻量去雾权重 or 自训；评估 `clean→fog→dehaze→detect` 的整链。
- 联合路线（正牌 Baseline）：
  - 去雾网结构建议：估计 $$t(x)$$（1 通道）+ $$A$$（3 通道），重建 $$\hat{J}=(I_f-A)/t + A$$；
  - 损失权重：$$\lambda_r=0.05$$（轻像素监督，防止去雾网自由漂移），$$\lambda_{yolo}$$ 主；
  - 训练技巧：不可见样本（A3-01 `invisible_flag`）对 $$\mathcal{L}_{yolo}$$ 降权，但保留 $$\mathcal{L}_{recon}$$（去雾本身仍可学）。
- 推理链路：`I_f → G → D → 后处理`；报告"去雾前处理 + 检测"总时延。

## 四、数据层

- 训练：A3-01 配对集（合成雾）。像素级 clean 真值（$$I_c$$）在训练时天然可用——这正是配对数据的优势，也是去雾路线的数据依赖（**特征一致性不需要它**，这是路线对比的一个论点）。
- 域外评估：RESIDE ITS / RTTS / DENSE fog 等真实雾图（同 A3-01 的 sanity check 协议）。真实雾没有配对 clean，因此只能评估**端到端检测指标**，不能算像素级 PSNR。

## 五、可能踩的坑

1. **过平滑与伪纹理**：去雾网输出被抹平，裂纹/腐蚀细节被擦掉，检测掉点比不上雾更惨。FN 审计必须单独报告"去雾引入的 FN"。
2. **Halo 与颜色偏移**：传输图估计在边缘跳变处产生 halo；海雾偏蓝场景下颜色校正过头。用边缘区域 mAP 单独统计。
3. **像素级 PSNR 好但检测差**：像素还原与检测任务是两回事；论文以检测指标为主，PSNR/SSIM 只作参考并注明"不直接对应检测性能"。
4. **延迟翻倍被忽略**：去雾一次前向 + 检测一次前向；若只在图上比较不报告时延，就是偏颇。端到端 P95 必须与特征一致性并列。
5. **梯度冲突**：检测损失希望保留缺陷细节，像素重建希望平滑——联合训练时两者打架。$$\lambda_r$$ 必须在 val 上扫描并记录曲线。
6. **过拟合合成雾**：去雾网学会"对灰雾去雾"，遇到真实偏蓝海雾直接崩。域外测试是必须的，崩了就如实写。
7. **把级联与联合混称"本文方法"**：论文里明确级联/联合都是 Baseline，本文方法是 A3-02 特征一致性。

## 六、评估指标与消融设计

- 与 A3-02 同表：每 $$\beta$$ 档 mAP@0.5 / P / R / FN；追加端到端时延 P95。
- 去雾输出质量：PSNR、SSIM（合成配对上有真值；域外真实雾无真值，仅测检测）。
- 伪影审计：`dehaze_introduced_fn.csv`（在原图已可见、去雾后反而漏检的框）。
- 消融：联合 vs 级联 vs 特征一致性（A3-02）；$$\lambda_r \in \{0, 0.05, 0.1\}$$；有/无不可见降权。

## 七、论文写法

可写：

> 作为对比基线，任务驱动去雾联合检测在 β=1.5 档 mAP@0.5 为 X，但端到端时延为 Y（为仅检测的 Z 倍）；本文特征一致性方案在相近精度下保持与仅检测一致的时延。

禁写：`去雾后检测精度提升`（若无独立 test 与消融）、`去雾网络消除了海雾影响`（无域外证据）、把 PSNR 当作检测性能。

## 八、诚实自评锚点

- **可交付**：联合/级联/特征一致性三路线同表 + 端到端时延 + 伪影审计。
- **部分完成**：只做了级联 → 只报告级联结果，不写联合路线结论。
- **不可声称**：去雾提升检测泛化（无域外证据）、像素还原质量等同任务收益。
- **停止线**：配对数据不可复现、或无法报告端到端时延差异时，停止去雾路线结论。
