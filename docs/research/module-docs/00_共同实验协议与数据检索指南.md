# 共同实验协议与数据检索指南

建立 manifest：`image_id,source_id,blade_id,flight_or_video_id,capture_date,width,height,sha256,split,reviewer`；按来源组划分并锁定 test。

数据检索从 [Kaggle](https://www.kaggle.com/datasets)、[Roboflow Universe](https://universe.roboflow.com/)、[Papers with Code](https://paperswithcode.com/datasets)、[OpenML](https://www.openml.org/)、[VisDrone](https://github.com/VisDrone/VisDrone-Dataset)、[SeaDronesSee](https://github.com/Ben93kie/SeaDronesSee) 开始。记录许可证、版本、下载哈希、模态、域差异和再分发权限；许可证不清的数据不得进入主 test。

所有均值给 N 和离散程度；视频帧不冒充独立样本；提升同时给绝对差值和相对比例。
