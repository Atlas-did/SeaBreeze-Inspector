# P1-04 · B1 EKF 消融改造 —— 让「自适应 Q」这个核心卖点真正站得住

> 对应计划:`SeaBreeze_攻坚计划_v1.md` P1-4 · 证据脚本 `research/专项/B1/ekf_ablation.py`
> 一句话结论:**当前消融结论「扫 Q 没有区分度」是玩具模型自带的假象,不是系统的真实性质**。根因是简化仿真里加速度状态 `acc` 与扰动状态 `d` 在观测方程中共线、不可区分,滤波器把 IMU 观测五五分给了两个状态。真正的系统(d扰动观测器)靠「减去已知控制加速度 u」让 d 直接可观测,消融脚本恰恰丢了这一步。改造后消融要测的就不是「扫 Q 有没有用」,而是论文真正声称的东西:**固定 Q vs 自适应 Q 的跟踪延迟对比(800 → 280 ms)**。

## 2. 问题定位(全部实测)

### 2.1 报告里的反例数字(`reports/ekf_ablation_report.json`,脚本默认参数直接产出)

```
conservative (Q_d=0.1):  step_rmse=0.798   innovation_std=0.300
moderate     (Q_d=0.5):  step_rmse=0.799   innovation_std=0.317
aggressive   (Q_d=2.0):  step_rmse=0.800   innovation_std=0.322
static_baseline:          d_hat_std=0.109  (应≈0)
```

三档 Q 跨 20 倍,Q 变 RMSE 只动 0.002——消融完全无区分度。

### 2.2 脚本本身(`research/专项/B1/ekf_ablation.py`,关键行)

- 注释自称「12 状态简化版」,**实际只有 4 状态** `[pos, vel, acc, d]`,只仿 x 轴。
- 观测矩阵 `H = [[0,0,1,1], [1,0,0,0]]`——加速度观测 `z0 = acc + d`;位置观测 `z1 = pos`。
- `Q = diag([0.01, 0.1, Q_d, Q_d])`;**acc 和 d 的过程噪声都是 Q_d**。
- `R = diag([0.05, 4.0])`——位置观测噪声 σ=√4.0 = **2 m**。
- 三档配置 `conservative/moderate/aggressive` 只扫 `Q_d ∈ {0.1, 0.5, 2.0}`,`R` 完全没扫。
- 全程没有控制输入 u,没有自适应 Q 机制。

### 2.3 我做的根因诊断(50000 步重跑 + 逐项隔离,可复现)

```
逐项隔离:
  基线(Rpos=4.0):        RMSE=0.799  d_hat 最终值=0.901
  Rpos=0.01(光流级):     RMSE=0.799  d_hat 最终值=0.901   ← 位置噪声不是主因
  Racc=1e-4(IMU级):      RMSE=0.791  d_hat 最终值=0.995   ← 加速度噪声改善很小
  两者都修:              RMSE=0.791  d_hat 最终值=0.995

step 响应(修复后):
  k=490  d_true=1.0  d_hat=0.504   ← 真值 1.0,只估计到一半
  k=505  d_true=2.0  d_hat=1.000   ← 阶跃后又是正好一半
```

**结论:RMSE 0.79 不是噪声造成的,是系统性跟踪偏差——滤波器把「acc+d」的观测在 acc 与 d 两个状态间对半劈开(0.504 ≈ 1.0/2)。** 因为:

1. 观测 `z0 = acc + d`,acc 和 d 都以「常值」动态进入状态方程(转移矩阵里两行都是单位项);
2. 两者过程噪声同为 Q_d,先验 P0 都很大;
3. 滤波器从单一观测无法区分「是加速度在变」还是「是扰动在变」——信息矩阵里 acc 与 d 完全共线;
4. 后验估计于是按先验比例(相等)把测量分给两者 → 各得一半。

**对照真实系统(这层最关键)**:`backend/core/disturbance_observer.py` 是 12 状态 `[x,y,z, vx,vy,vz, ax,ay,az, dx,dy,dz]`,观测 `Z=[a_imu, x_opt, z_bar]`,但 **update 里有两行关键代码**(L346-347、L351):

```python
# 如果有控制输入, 从IMU观测中减去已知控制量
z_adjusted[0:3] -= self._last_u[0:3]
# IMU预测 = dx_pred (ax部分已在z_adjusted中减去)
z_pred[0:3] = self.x[IDX_DX:IDX_DX+3]
```

即:**真实观测器用「IMU 实测加速度 − 已知控制加速度 u」作为扰动观测的新息**,d 直接可观测,根本不存在 acc/d 共线问题。它还实现了自适应 Q(Mahalanobis 距离 D² 超过 χ²₆(0.95)=12.59 时 `Q = Q_base × (1 + α(D²/th − 1))`,`α=0.3`,限幅 10,L390-414)。

**一句话根因:B1 消融脚本是真实观测器的一个"失真简化"——丢了 u 馈入导致 d 不可观测,丢了自适应 Q 导致根本没测论文声称的东西。它的「Q 无区分度」结论不能代表真实系统。**

## 3. 改造方案(三块,全部纯本地 CPU)

### 3.1 块一:重构仿真,让 d 可观测(忠实还原真实观测器)

把 `run_ekf` 改成「带控制输入的真实扰动观测逻辑」,而不是在旧玩具上打补丁:

```python
# 每个时刻:
#   控制指令 u[k] 由仿真控制器给出(例如前馈+反馈,或直接设已知加速度)
#   真值: x[k+1] = F @ x[k] + B @ u[k] + (扰动作用于加速度通道: d 叠加在 a 上)
#   观测: a_imu = u[k] + d[k] + N(0, σ_acc)      ← 已知 u,所以新息直接观测 d
#         x_opt = x[k] + N(0, σ_pos)              ← 光流位置,σ 取真实量级(0.01~0.1 m)
#   滤波: 观测新息对 d 的增益接近 1,不再五五分
```

具体到脚本:状态可保持 4 维 `[pos, vel, acc, d]`,但必须:
1. **给观测器喂 u**(仿真里控制量已知),新息 `y = (a_imu − u) − (acc_pred + d_pred)`;这样 acc 的贡献由控制量承担,d 独占新息。
2. **R 按真实传感器量级重设**:位置观测 σ 取光流量级 0.01–0.1 m(当前 2 m 是硬伤),IMU 加速度 σ 取 0.05–0.2 m/s²。
3. 场景保留 `step / sine / static`,额外加 `gust`(随机幅值脉冲,考验自适应触发)。

### 3.2 块二:主消融 = 固定 Q vs 自适应 Q(论文卖点的直接实验)

这是改造后的**主实验**,替代「扫 Q」:

| 对比组 | Q 策略 | 指标 |
|---|---|---|
| 固定 Q(基线) | Q 恒为 Q_base | 阶跃后收敛时间(到稳态 ±5%)、超调、稳态 RMSE |
| 自适应 Q | 按 Mahalanobis 距离临时放大 Q | 同上 |

指标改用**跟踪延迟/收敛时间/超调**(对应论文的 800 → 280 ms 声称),不再只看 RMSE——RMSE 会把「前期慢、后期好」抹平,收敛时间才能体现自适应 Q 的价值。输出一张时间响应图(横轴时间,纵轴 d_true vs d_hat 两条曲线,fixed 与 adaptive 并排)+ 一张指标表。预期结果:自适应 Q 的收敛时间显著短于固定 Q(这是论文要的数字,跑出来是什么就写什么,不预设)。

### 3.3 块三:次消融 = Q×R 二维网格(说明「什么时候 Q 重要」)

扫 `Q_d ∈ {0.05, 0.5, 5.0}` × `R_acc ∈ {0.01, 0.1, 1.0}`,输出 3×3 RMSE + 收敛时间表。目的:证明「Q 影响跟踪速度、R 影响噪声抑制」两者解耦,并且找到使滤波器既不迟钝也不过冲的工作区间——这是给论文「参数选择」小节准备的表。

### 3.4 静风基线

改造后重跑 `static` 场景,d_hat std 应降到观测噪声地板(与 σ_acc 同量级,期望 < 0.05)。若仍异常偏高,说明模型里还有未解释的偏差源,先查清楚再写进论文,不许带病交卷。

### 7.2 u 馈入 bug(用户实测 → 本机复现 → 已修复)

- **现象**:把已知控制加速度 u 设为非零(如 1.0)时,d_hat 稳态偏到 ≈2.99,而 d_true=2.0。
- **根因**:`run_ekf` 的 update 一步新息 `y = z - H @ xh` **从没减 u**。L7 注释写着「新息 y_acc = (a_imu-u) - d_hat」,代码却直接拿 `a_imu` 当 d 的观测——注释与代码不一致。u=0 时数值恰好对(所以消融数字一直没问题);一设非零,u 就被滤波器当成扰动吃进 d_hat(d_hat → d_true + u)。真实 `disturbance_observer.py` L346-347 是正确减 u 的,这里只是消融脚本的失真。
- **修复**:update 一步加 `y[0] -= u[k]`;u 暴露为 `--u-const` 参数(默认 0,主消融数字不变);report 新增 `u_feed_check` 自检锁死该机制。
- **验证**(`ekf_ablation.py --u-const 1.0`):u=1.0、d_true 阶跃 1→2 时,d_hat 尾部均值 **1.995 ≈ 2.0** ✅;修复前同场景 2.994 ❌。u=0 主消融 480/250ms、超调 2.4%、稳态 RMSE 0.0140 **全部不变**。

### 7.3 「零稳态代价」结论 → 论文讨论段(可直接粘贴)

> 自适应 Q 在将阶跃扰动跟踪收敛时间从 480 ms 缩短至 250 ms 的同时,不付出稳态代价:两种策略的稳态估计误差均为 0.0140 m/s²(RMSE,阶跃后 30% 窗口),超调均为 2.4%,静风基线下 d_hat 标准差 0.0103 m/s² 处于 IMU 加速度观测噪声量级。这表明 Q 自适应仅在瞬态放大估计带宽,收敛后自动回到低增益,不引入额外稳态抖动——与固定 Q 相比,这是「参数鲁棒性」之外的第二个可写卖点,实验上直接以两张曲线在阶跃后重合佐证。
