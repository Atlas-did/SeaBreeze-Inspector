## §5.6 缺陷检测

### 5.6.1 数据集与划分

**正文(数字按最终运行填)**:

> 检测实验基于风电机组叶片巡检图像数据集,经逐图 SHA-256 去重后共 **N 张唯一内容**,按内容级划分(train : val : test = **X : Y : Z**),**三向零碰撞**(同一张图的任何变体不跨 split)。数据清洗流程:① 拉普拉斯方差清晰度筛选(阈值 50);② 大模型辅助标签审查(剔除误标注样本);③ 类别口径定义为 **二分类(defect / clean)**,原始三缺陷类(crack / corrosion / leading-edge damage)作为标注元数据保留。

**必须同时出现的证据**:
- [ ] 泄漏审计:`audit_manifest_leakage.py` 的输出 JSON(附 train/val/test 两两交集=0);
- [ ] 数据构成表:每 split 的行数、唯一内容数、正负样本比(标注比例应写清,类别不平衡是下节局限性的依据);
- [ ] 数据来源声明(data_sources.csv,含 CC BY 4.0)。

### 5.6.2 训练协议

**正文(与 args.yaml 逐字段一致,禁止手写)**:

> 模型为 **YOLO11s**(最终选定架构),输入分辨率 **1024×1024**,batch=8,共训练 **200 epochs**(早停 patience=50),优化器与超参数为 ultralytics 默认,数据增强固定为 fliplr=0.5 / mosaic=1.0 / hsv(H=0.015, S=0.7, V=0.4)。训练随机种子 seed=**0**。最佳检查点按验证集 **mAP50-95** 选取。

**必须同时出现的证据**:
- [ ] 每轮训练的 `args.yaml`(train_cli.py 训练后回读自检通过);
- [ ] 训练损失/指标曲线图(epochs × mAP50 / mAP50-95 / loss);
- [ ] 若多轮(binary/multi × 11s/8s):一张"协议固定项对照表",证明除刻意变化的项外其余参数一致。

### 5.6.3 评估指标

> 指标采用 COCO 风格的 **mAP50、mAP50-95**,以及 **Precision、Recall、F1**(置信度阈值按验证集 F1 最优选取),并分尺度报告 **AP_S / AP_M / AP_L**(小目标占比 **56.8%** 是本数据的核心难点)。
