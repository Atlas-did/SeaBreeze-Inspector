## 2. 问题定位(全部实测)

### 2.1 报告数字(`reports/wind_resistance_report.json`)

```
N_valid=5000
vmax_mean=8.18, P5=6.98, P50=8.13, P95=9.51
p_ok_12ms = 0.0   ← 5000 个样本没有一个能扛 12 m/s(6 级)
p_ok_10ms = 0.0   ← 连 10.8 m/s(6 级下限)都扛不住
p_ok_14ms = 0.0
```

注意 `platform_x500.yaml` 里参数是区间(如 `mass_kg: [2.5, 4.5]`、`T_continuous_N: [18, 30]`),5000 次蒙特卡洛采样后 **没有一个样本 vmax≥10.8 m/s**——说明连参数区间的乐观一端都不够,这不是「参数没取好」,是**模型结构层面水平约束(阻力)压过了参数区间**。

### 2.2 Bug 一:敏感性打印顺序不一致

`wind_resistance_model.py` L84:

```python
report['sensitivity'] = dict(sorted(sens.items(), key=lambda kv: -abs(kv[1]['range'])))
```

report 是按 |range| 降序排的(正确)。但 L92 打印用的是未排序的插入字典:

```python
print(f"  敏感性排序: {', '.join(sens.keys())}")
```

`sens` 的插入顺序是 `mass_kg, T_continuous_N, theta_max_deg, C_D_Aeff_m2`,与报告里的排序 **C_D_Aeff_m2 → theta_max_deg → T_continuous_N → mass_kg 正好相反**。若有人照着 print 输出写论文,会把「质量最敏感」抄进去——**错**。

修法(一行):
```python
print(f"  敏感性排序: {', '.join(report['sensitivity'].keys())}")
```

### 2.3 隐藏发现:质量对 vmax 零影响(range=0.0)

报告敏感性里 `mass_kg: {lo: 8.025, hi: 8.025, range: 0.0}`——**质量区间 2.5~4.5 kg 对 vmax 没有任何影响**。这不是 bug,是模型结构使然:

- 抗风能力由双约束决定:垂直约束 `T·cosθ ≥ mg/ηv`、水平约束 `T·sinθ ≥ D(v)/ηh`。
- 在 x500 的参数区间里,垂直约束始终不生效(θ_v > θ_max,即「还没倾到最大角,升力就够抵消重力了」),于是水平约束单独决定 vmax:`v_max = √(2ηh·T·sinθ_max / (ρ·CdA))`,里面根本没有质量。
- **推论(对论文有用)**:x500 的短板不在「重、抬不起」,而在「倾角权限和迎风面积」。想扛 6 级风,优先做两件事:降 CdA(流线化机身、折叠起落架)或提 θ_max(飞控限幅放宽)。这不是拍脑袋,是敏感性排序直接指出来的。

### 2.4 模型的本征局限(必须写进论文)

`v_max = √(2F_h/(ρ·CdA))` 是**准静态力平衡天花板**:它假设无人机能在恒定侧风里保持稳态悬停。真实的作业风况上限由三样东西共同决定,模型一个都没包含:

1. **阵风动态**(风不是恒定的,有阵风谱、突风脉冲);
2. **控制带宽**(能否在阵风到达的一个控制周期内把它抵消——这才连上 B1 的「自适应 Q 收敛 280ms ≈ 3.6Hz 带宽」);
3. **扰动容忍度**(姿态摆动多少以内算「可作业」,取决于感知/机械臂能否工作)。

所以模型给出的 8.2 m/s 是**物理天花板上限,不是作业包线**。论文的正确表述是:「设计假设下的准静态抗风极限约 8 m/s;考虑阵风动态与控制带宽,实际可控风况更低;6 级风(12 m/s)作业能力需工业平台实测验证。」

### 3.4 论文详细局限性讨论素材(你决定把 8 m/s 写透,这段直接可改)

> **抗风能力局限**。本文抗风分析基于经小型机实测部分校准的准静态力平衡模型。在设计假设参数下,模型的稳态抗风极限约为 8 m/s(5–95% 区间 [7.0, 9.5] m/s),该值远低于 6 级风(10.8–13.8 m/s)下界,5000 次蒙特卡洛采样中无一达到 6 级风下界。敏感性分析表明,限制因素为水平推力对抗风阻力的裕度,其中迎风阻力系数与投影面积的乘积 C_d·A_eff 影响最大(灵敏度 1.84 m/s),最大倾角权限次之(1.51 m/s),质量在上述参数区间内对极限风速无影响。这意味着小型机/教学原型的抗风瓶颈主要来自机体阻力与倾角权限,而非推力。**模型未包含阵风动态、控制带宽与姿态扰动容忍度,故 8 m/s 为物理上限而非作业包线**;结合自适应 Q 的等效带宽(~3.6 Hz)与阵风主频(< 1 Hz)的分析,本文认为该方案具备进一步验证的潜力,但 6 级风下的作业能力必须依托工业平台(如 X500 级)实测确认。
